## 一、项目总览

语义回响是一整套"让 AI 表达更有情感"的推理期架构。核心思想始终不变：**情感先于表达**——不是教模型"说情感词"，而是让模型在底层先"处在某种情感状态"，再让它自然表达。

|---|---|---|---|---|---|---|---|

| P2.5 | 情感潮汐解码 ETD | **概率空间** | 外部 VAD 感知 → 采样乘性重加权 + 情感词预算 + AI腔抑制 | 否 | 可选 | ✅ | 潮汐回响混合 v4.2 +91% |

## 二、底层原理（家族不变的根基）

1. **情感是底色，不是标签**：注入的是"情感状态向量/分布"，而非简单加几个情感词。
2. **作用在生成期（推理期）**：不训练、不改基座，任何已部署模型可即插即用。
3. **表达自由度优先**：所有方案内置"在线退化兜底"（熵<阈值 → 自动降强度/归零），保证任何模型不掉线、不坍缩。
4. **情感来源多样化**：P1 来自模型自身 hidden_state（自我回响）、P2.5 来自外部文本感知（VAD）、P3/P4 来自模型词表或注意力缓存、P5 全部融合。

**继承关系**：P1 证明"情感向量注入"有效但依赖钩子；P1.5 让注入强度全模型自动适配；P2.5 摆脱内部依赖（外部 VAD + 概率空间，数学上不可能坍缩）；P3 把"质心投影"从 hidden_state 迁移到静态 embedding 接口（只读、可降级闭源 API）；P4 在注意力缓存上让模型"看向"情感内容（softmax 归一化天然有界）；P5 把四者耦合进同一条注入链路（一体化全合成）。

## 三、各方案详解

### P1 语义回响（表示空间 · 内循环）

**机制**：forward hook 捕获最后 N 层 hidden_state → 情感筛选入池 → 池质心 `@` 随机投影矩阵 → `logits += 偏置×λ`。升级版加入思考链中断。

**关键实验（0.5B，E1-E13 分批）**：

| 批次 | 内容 | 关键结果 |
|---|---|---|
| 批次1 (E1-E6) | λ 扫描 0.1~1.0、回响池可行性 | λ=0.5 细腻度 **+17.9%**，U 型曲线复现 |
| 批次2 (E7-E10) | 情感词库筛选 + 思考阶段分离 | 命中率 0.23→0.40（E9） |
| 批次3 (E11-E13) | 完整方案 + 保留策略 | E13 全局保留最稳（熵 1.9372/命中 0.22） |
| 批次4 | 跨尺度泛化（1.5B/7B 4bit） | **灾难性坍缩**（重复率 83%~98%）→ 负样本催生 P1.5 |

**边界**：跨尺度 λ 需归一化；Qwen3 系对注入极度敏感；必须本地权重（钩子），闭源 API 不可用。

### P1.5 通用兼容层 V2（配置空间 · 调度）

**机制**：四级归一化——扫描表优先、公式兜底、架构族因子、量化因子（4bit ×0.75）。未注册模型走"保守 λ 回响 + 思考链中断"双兜底；全程在线坍缩检测。

**关键实验**：

| 批次 | 内容 | 关键结果 |
|---|---|---|
| 多模型对照 | 19 配置 ×5 runs | Qwen2.5 系全绿（熵+27~45%）；Qwen3 系坍缩 → 因子修复 |
| Qwen3 重测 | 架构族因子生效 | 全部 6 配置改善，Qwen3-4B 重复 0.18→0.06 |
| 思考链中断 | 三组同种子 | Qwen3-1.7B 从坍缩（重0.84）拉回健康（重0.0036） |
| 全链路验证 | 已注册 vs 未注册 | DeepSeek-7B 未注册兜底命中 0.2166 ≥ 已注册 0.1572 |
| LoRA 融合 | 外挂+回响 | 熵 **+217%~457%** |

**边界**：本质是"调参调度器"，本身不产生新情感机制；仍依赖本地权重。

### P2.5 情感潮汐解码 ETD（概率空间 · 外循环）

**机制**：三层——感知层（VAD 文本测量 + 会话轨迹"潮汐"）→ 决策层（共情目标 + 自适应引导强度 α）→ 表达层（采样分布乘性重加权 `p' ∝ p^(1-α)·q_emo^α`，数学上不可能坍缩）。迭代出 AI 腔三通道抑制（v4）、身份拦截 + 句子硬停止（v6）、人设系统提示 + 多候选自选（v8）。**潮汐回响（回响×潮汐混合方案）= P1 × P2.5**——混合注入器 v4.2 达 LLM-Judge +91%。

**关键实验（M 里程碑分批）**：

| 里程碑 | 内容 | 关键结果 |
|---|---|---|
| M4 | 裸 vs 潮汐 | 熵+0.053、重复率 0、命中+0.005 |
| M5b-d | EmoCharacter / HeartBench | 一致性识别率 0.6→0.7（+16.7%）；HeartBench -2.97（适用边界） |
| M5e | 潮汐回响混合（P1×P2.5） | LLM-Judge 30 样本 **+18.2%** |
| M5f | v4 AI腔三通道抑制 | 潮汐回响混合 v4.2 **+91%**（0.1833→0.35） |
| M5g | 多模型横向 | 1.5B 混合 +87.5%、3B 潮汐 +33% |
| M5h/i | v6-v8 定向优化 | 混合 v8+人设 N5 **0.5167（+48%）** |

**边界**：词库稀疏打分；情感表达/共情任务专用，通用"人味儿"（HeartBench rubric）反而不利（-9.4%）。

### P3 锚点回响 AE（嵌入空间 · 接口映射）

**机制**：读取模型自身 `get_input_embeddings()` 权重（**只读，零修改**）→ 6 维情感锚点质心 E → 候选 token 稠密余弦打分 `S[w,k]=cos(W_e[w], e_k)` → 极性定向注入 `logits += β·tanh(S·v_target/T_anchor)`。三通道 `混合锚点器` = 锚点 × 回响 × 潮汐 正交可叠加。自动适配沿用 P1.5 体系（扫描表五元组 + 因子）。三级接口降级。

**关键实验（分批）**：

| 批次 | 内容 | 关键结果 |
|---|---|---|
| 批次0 | 灵感验证 | 方向分离度 t=12.12、只读证明（sum/指针不变）、近义覆盖 7/10 |
| 批次1 | 单模型对照 | 无坍缩、命中率提升；熵收窄问题定位 |
| 批次2 | 参数扫描 | 最优 β=0.8/T=0.3/K=6；熵恢复 **1.0995×裸**、命中+3.0pp |
| 批次3 | 五基准 | LLM-Judge **+56.25%**（+人设）、HeartBench **+21.7%**、TuringBench **+200%** |
| 批次4 | 多模型 | Qwen3-1.7B +6.91%、gemma-2-2b +28.53%（未注册兜底） |
| 批次5 | 三正交+双裁判 | 本地 7B 全开 **+55.6%**、deepseek-v4-pro +100% |
| 批次6 | 接口降级 | logprobs 熵差 0.67% 逐字一致；提示模式零内部访问 |

**边界**：纯净单模式 LLM-Judge 提升有限（+12.5%，加人设后 +56.25%）；EmoCharacter 受 1.5B 模板天花板限制。

### P4 KV 情感共振解码 KER（注意力缓存空间 · 共振）

**机制**：P3 的稠密打分表升级为"注意力导航图"——在 KV 缓存中定位情感 token，对其 key 做有界缩放 `K_l[:,:,p,:] *= (1 + κ·clip(S[token_p]·v_eff, 0, 1))`，使模型注意力向对话中的情感内容共振。情感方向 `v_eff = normalize((1-γ)·v_target + γ·v_dyn)` 融合外部 VAD 目标（P2.5）与模型内心 hidden_state（P1 DSA）。**不写权重、不改 logits、softmax 归一化使调制天然有界**。

**关键实验（2026-08-10，30 条样本，每模式独立种子）**：

| 模式 | 熵 | 重复率 | 命中率 | 长度(字) | win_rate | 相对裸 |
|---|---|---|---|---|---|---|
| 裸 | — | — | — | 122.7 | 0.2167 | — |
| 锚点P3（种子200） | 1.619 | 0.008 | 0.159 | 52.7 | 0.1167 | -46% |
| 超融合DMR（P5） | 1.701 | 0.003 | 0.130 | 49.8 | 0.1667 | -23% |
| P4-KER 单通道 | 1.545 | 0.005 | 0.154 | 45.1 | 0.1167 | -46% |
| **P3+P4 双通道** | **1.706** | 0.005 | 0.133 | **43.1** | **0.2667** | **+23%** |

**结论**：P3×P4 双通道全场最高（+23%）；P4-KER 单通道不敌裸（1.5B AI 腔未抑制）；换种子验证显示绝对胜率对种子高度敏感，未来需多种子平均。

### P5 超融合解码器 UFD（全空间机制级融合 · 合成方案）

**机制**（源码 `超融合解码器.py`，文件头标注「P1×P2×P3×P4 四架构底层融合」）：与"混合锚点器"的三通道加性叠加不同，P5 做**机制级融合**——一体化全合成 P1+P2+P3+P4：
- **① DSA 动态自参照锚点（P1×P4）**：每步捕获最后一层 hidden_state h_t（轻量只读 hook），`v_dyn[k]=cos(h_t, e_k)`，`v_eff=normalize((1-γ)·v_target+γ·v_dyn)`——P1 自我回响思想在 P4 嵌入接口落地，用 K×d 锚点矩阵替代 P1 的 933MB 随机投影；
- **② DMR 稠密乘性重加权（P3×P4）**：用 P4 稠密打分表构造 `q_emo(w)=softmax(S[w]·v_eff/T_emo)`，再以 P3 乘性形式注入 `logits'(w)=(1-α)·logits(w)+α·log q_emo(w)`——同时获得 P3 的"不可能坍缩"与 P4 的"全词表覆盖"，补足 P3 稀疏词表 OOV 短板；
- **③ P1.5 贯穿**：α/β 走目标决策器自适应输出（扫描表/公式兜底/架构族因子）。

**关键实验（2026-08-10，Qwen2.5-1.5B，种子 42）**：

|---|---|---|---|---|---|
| 裸 | 1.3717 | 0.0 | 0.0 | 198.2 | 0 |
| 锚点P3 | 1.4613 | 0.0223 | 0.1593 | 66.2 | 0 |
| 混合全开 | 1.529 | 0.0091 | 0.1936 | 51.6 | 0 |
| 超融合DMR | 2.034 | 0.0185 | 0.1411 | 62.0 | 0 |
| 超融合全开 | 1.7293 | 0.0105 | 0.1439 | 57.4 | 0 |

LLM-Judge（30 条/60 配对）：种子42 时超融合DMR 0.1833（裸 0.2333）；独立种子时 0.1667（-23%），P3+P4 双通道 0.2667（+23%）。

**结论**：P5 健康度优异（熵 1.7~2.0、重复率 ≤0.019、兜底 0）证明"四架构同链路底层融合"可行且安全；但 DMR 单通道 win_rate 0.1667~0.1833 不及 P3+P4 双通道——1.5B AI 腔未抑制时单通道不敌裸，需叠加 P2.5 人设/AI腔抑制；P5 当前为"机制验证"阶段，是商业化"完全体"（P1+P2+P3+P4 全合成）的技术对应。

## 五、方案关系：正交可叠加 + 一体化全合成

```
P1 表示空间（hidden_state 回响）──── 情感底色/细腻度
P1.5 配置空间（自动适配）─────── λ/γ/τ/β/κ/α 调度总开关
P2.5 概率空间（潮汐重加权）────── 方向 + 密度控制 + AI腔抑制（潮汐回响 = P1×P2.5 混合）
P3 嵌入空间（锚点稠密引导）────── 词表坐标级情感温度校准（logits 注入）
P4 注意力缓存空间（KV 共振）──── 让模型"看得到"情感内容（注意力调制）
P5 全空间融合（UFD 超融合）──── 一体化全合成 P1×P2×P3×P4（DSA + DMR + 参数贯穿）
```

- 混合注入器（P2.5，潮汐回响 = P1×P2.5）：回响×潮汐 叠加正边际（+18.2%），v4.2 达 **+91%**
- 混合锚点器（P3）：锚点×回响×潮汐 三通道叠加，本地 7B 全开相对裸 **+55.6%**，双裁判方向一致
- **P3+P4 双通道**（P4 验证）：锚点 logits × KV 注意力 正交叠加，win_rate **0.2667（+23%）全场最高**
- **P5 超融合（合成方案）**：四架构机制级融合进同一条注入链路（DSA/DMR/P1.5 贯穿），健康度无坍缩
- P3 打分表内存仅 3.6MB vs P1 投影矩阵 933MB；P4/P5 显存增量 ≈0

## 七、边界与局限（诚实清单）

1. **P1**：钩子依赖本地权重；Qwen3 系易坍缩；跨尺度迁移灾难性坍缩。
2. **P1.5**：调度器非新机制；仍需本地权重；长上下文（512+ tokens）坍缩未解决。
3. **P2.5**：词库稀疏（网络流行语识别弱）；HeartBench 类"自主性"任务反作用；混合限 Qwen2 系。
4. **P3**：纯净单模式 LLM-Judge 增益有限（需人设增强）；EmoCharacter 受小模型模板天花板限制；3B 泛化方差内负向。
5. **P4**：单通道不敌裸（1.5B AI 腔未抑制）；KV 调制需本地缓存；κ/层数/V 调制未扫描；仅单模型实测。
6. **P5**：超融合 DMR 单通道胜率不及 P3+P4 双通道；处于机制验证阶段（未完成五基准/多种子/多模型评测）；DMR 熵偏高；闭源 API 需降级。
7. **共通**：1.5B 基模表达力是最终瓶颈——解码期引导只能缩小差距，无法突破基座天花板。
