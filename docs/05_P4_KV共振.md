# P4 KV 情感共振解码 KER（KV Emotional Resonance）

> **一句话**：在**注意力缓存空间**做有界调制——不写权重、不改 logits，让模型"看得见"对话里的情感内容。
> **操作空间**：注意力缓存空间｜ **改权重**：否（运行时缓存）｜ **代表成果**：P3×P4 双通道 LLM-Judge **0.2667（+23%）全场最高**；显存增量 ≈0。

---

## 1. 核心机制

1. P3 的稠密打分表升级为"注意力导航图"——在 KV 缓存中定位情感 token；
2. 对情感 token 的 key 做有界缩放：`K_l[:,:,p,:] *= (1 + κ · clip(S[token_p]·v_eff, 0, 1))`；
3. 情感方向 `v_eff = normalize((1-γ)·v_target + γ·v_dyn)` 融合外部 VAD 目标（P2.5）与模型内心 hidden_state（P1 DSA）；
4. softmax 归一化使调制**天然有界**，不会爆炸。

## 2. 优点

- **不写权重、不改 logits**：只动运行时 KV 缓存；
- **softmax 天然有界**：数学上无坍缩风险；
- **显存增量 ≈0**：K×d 锚点矩阵运行时生成；
- **叠加增益最高**：P3×P4 双通道（锚点 logits × KV 注意力）win_rate 0.2667（+23%）全场最高；
- **方向可融合**：目标向量能混合 P2.5 外部感知与 P1 内部回响（DSA）。

## 3. 缺点与局限

- **单通道不敌裸**：1.5B AI 腔未抑制时 P4-KER 单通道 0.1167（-46%）；
- **需本地 KV 缓存**：`past_key_values` 不暴露的 API 需降级；
- **参数未扫描**：κ/层数/V 调制未系统扫描；
- **仅单模型实测**（1.5B），多模型泛化未做。

## 4. 适用场景

- 与 P3（或 P5）**正交叠加**使用（双通道是它唯一出彩的方式）；
- 有本地 KV 缓存可访问的推理框架；
- 希望"注意力级"控制（模型真正注意情感内容）的进阶研究。

## 5. 不适用场景

- **单独使用**（单通道胜率负收益）；
- 无 KV 访问权限的闭源 API（需降级）；
- 追求回复长度自然性的场景（长度坍缩到 43 字）。

## 7. 边际效益分析

- **单通道边际为负**：单独调 κ 无法带来正收益（1.5B AI 腔是主要障碍）；
- **叠加边际为正**：P3+P4 双通道 +23%——交叉空间叠加的边际 > 单空间强化的边际；
- **γ 融合权重**：外部目标 vs 内部方向的混合比存在最优，偏离边际递减；
- **未扫描参数的潜在边际**：κ/层数/V 未扫描，理论上仍有上调空间（也是风险点）。
