# 11 · 测试指南（P1~P6 怎么测）

> 统一原则：**同一套样本、同一颗种子、同一裁判**，才能让 P1~P6 可比。所有方案都遵循本文档协议。

---

## 一、统一评测协议（全家族可比口径）

| 项目 | 设定 |
|---|---|
| 样本 | `样本_30条.json`（30 条，含真人 girl 回复） |
| 种子 | **2026**（每样本 种子=2026+序号-1；旁路由候选种子=基础+序号+k×7） |
| 采样 | temperature=1.0、top_p=0.9、top_k=50、repetition_penalty=1.05、max_new_tokens=128 |
| 模板 | `apply_chat_template`（各模型原版 chat 模板，**零前奏修改**） |
| 裁判 | Qwen2.5-7B-Instruct（bf16 手动分片加载），配对盲评 AB **正反各一次**（60 配对/模式） |
| 指标 | win_rate、平均熵、重复率（2-gram token）、情感命中率（情感 token 占比）、长度 |
| 兜底纪律 | 熵<0.6 或重复率攀升 → 注入强度减半重试，连续 3 次 → 归零纯裸采样 |

**运行环境**：Python 3.10/3.11、PyTorch（CUDA，RTX 3080 Laptop）、transformers 4.57.6（P1~P3）/ transformers 5.x + torch 2.6+（P4/P5/P6 要求）、cnsenti、jieba、peft/bitsandbytes。

## 二、五个图灵类基准（测什么）

| 基准 | 脚本（统一基准目录） | 指标 | 裁判 |
|---|---|---|---|
| LLM-Judge | `统一_run_llm_judge.py` | win_rate（AI vs 真人盲评 AB） | 7B |
| EmoCharacter | `统一_run_emocharacter.py` | 匹配 fidelity / 一致性识别率 | 7B |
| HeartBench | `统一_run_heartbench.py` | overall / 情绪维度（官方 rubric） | 官方 rubric |
| HEART-BENCH(FEEL) | `统一_run_feel_heart.py` | 共情 / 一致性 / 有效决策率 | 7B |
| TuringBench | `统一_run_turingbench.py` | human_likeness / 检测器准确率 | TF-IDF+LR |

> 统一基准代码位置（合体仓库内）：`01_P1_语义回响/图灵测试/统一基准/`（5 个 `统一_run_*.py` + 生成器/裁判子进程）。

## 五、新方案接入统一基准的清单（要测一个新方案照这个做）

1. 在统一生成器里注册新模式（输出必须含：回复文本、每 token 概率/熵、情感命中统计）；
2. 同种子同样本生成（种子 2026，30 条）；
3. 跑 5 个 `统一_run_*.py`；
4. 产出 `*_results_2026.json` + 健康度表（熵/重复率/命中率/长度）；
5. 多模型泛化（至少 3 个架构：Qwen2.5-1.5B / Qwen2.5-3B / Qwen3-1.7B）；
6. 多种子平均（当前教训：单种子绝对胜率波动大）；
7. 更新 `docs/09_跑分总表.md` 与对应方案文档。

## 六、历史口径注意

- **G 基准（2026-08-10）**：只有 裸/P1~P5 七模式，P2.5 最优 0.2667——这是 P6 的"必须超越"基线；
- **2026 全流程（P6 时代）**：7 模式 × 5 基准完整对照，P6 EDD 综合 0.7046 冠军；
- **P4/P5 专项（2026-08-10）**：每模式独立种子（裸100/锚点200/超融合300/KER400/双通道500），**绝对胜率对种子高度敏感**，未来评测需多种子平均；
- **P6 LoRA**：与 EDD 是两条互补路线（训练态 vs 解码期），评测协议相同（样本/种子/裁判一致）。
