# P3 锚点回响 AE（Anchor Echo）

> **一句话**：把 P1 的"hidden_state 质心投影"搬到**静态 embedding 接口**——只读、零修改、可降级到闭源 API。
> **操作空间**：嵌入空间｜ **改权重**：否（只读证明）｜ **代表成果**：LLM-Judge **+56.25%**（+人设）、HeartBench **+21.7%**、TuringBench **+200%**、P3×P4 双通道 0.2667 全场最高。

---

## 1. 核心机制

1. 读取模型自身 `get_input_embeddings()` 权重（**只读，零修改**，有 sum/指针不变的只读证明）；
2. 构建 6 维情感锚点质心 E（锚点库，打分表仅 **3.6MB**，vs P1 的 933MB）；
3. 候选 token 稠密余弦打分 `S[w,k] = cos(W_e[w], e_k)`；
4. 极性定向注入 `logits += β · tanh(S·v_target / T_anchor)`（β 强度 / T 温度 / K 维度可扫描）。

三通道 `混合锚点器` = 锚点 × 回响 × 潮汐，正交可叠加；自动适配沿用 P1.5 体系；三级接口降级（本地→logprobs→提示模式）。

## 2. 优点

- **零权重只读**：有完整只读证明（指针/求和不变），部署无合规负担；
- **闭源 API 可降级**：logprobs 熵差 0.67% 逐字一致，提示模式零内部访问；
- **跑分全面开花**：LLM-Judge +56.25%（+人设）、HeartBench +21.7%、TuringBench +200%（0.2333→0.7000）、本地 7B 全开 +55.6%、deepseek-v4-pro +100%；
- **内存极小**：打分表 3.6MB；
- **多模型泛化**：Qwen3-1.7B +6.91%、gemma-2-2b +28.53%（未注册兜底）；
- **可叠加性最佳**：P3×P4 双通道 win_rate 0.2667（+23%）全场最高。

## 3. 缺点与局限

- **纯净单模式增益有限**：不加人设时 LLM-Judge 仅 +12.5%；
- **EmoCharacter 天花板**：受 1.5B 模板天花板限制（裸 0.90 已饱和）；
- **3B 泛化方差内负向**：部分模型在方差内无正收益；
- **熵收窄问题**：早期版本注入后熵收窄（参数扫描修复后恢复 1.0995×裸）。

## 4. 适用场景

- 需要"零权重合规"的情感增强（对版权/审计敏感的场景）；
- 闭源 API / 云端模型（三级降级）；
- 与其他方案**正交叠加**（P1 回响 / P2.5 潮汐 / P4 KV）；
- 词表坐标级情感温度校准（logits 注入）。

## 5. 不适用场景

- 追求"不叠加任何东西、单通道就要惊艳"的场景（单通道胜率平庸）；
- 小模型 + 模板化任务的 EmoCharacter 评测（天花板饱和）；
- 需要词表外新词覆盖的任务（稠密打分对 OOV 弱，P5 DMR 补足）。

## 7. 边际效益分析

- **参数扫描的边际平坦区**：β=0.8/T=0.3 附近增益最高，偏离后边际递减，存在典型"甜蜜点"；
- **维度 K 的边际**：K=6 之后继续加锚点维度收益迅速饱和（锚点库覆盖已足）；
- **加人设是跳跃式增益**：+12.5%（纯净）→ +56.25%（+人设）——人设提示是更大的边际来源，锚点本身边际趋平；
- **叠加的边际为正**：P3×P4 双通道比单通道 +23%，说明正交叠加的边际 > 单通道调参的边际。
