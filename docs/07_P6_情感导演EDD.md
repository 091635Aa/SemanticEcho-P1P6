# P6 重点① 情感导演解码 EDD（Emotional Director Decoding）

> **一句话**：解码期"情感导演"——TAD（任务自适应强度）+ PIS（进度感知调度）+ OQC（在线质量纠正）三位导演，叠加五正交通道，**零权重、跨模型、即插即用**，2026 全家族冠军。
> **操作空间**：解码期零权重插件｜ **改权重**：否｜ **代表成果**：5 大基准综合 **0.7046**（超 P5 +12.6%）、LLM-Judge 胜率 **+122%**、多模型泛化 **+67%~+233%**。

---

## 1. 核心机制（三位导演 × 五通道）

**三个导演层（决策层）**：

| 机制 | 缩写 | 作用 |
|---|---|---|
| 任务自适应强度 | TAD | 探测任务类型：角色扮演 1.25 / 情感倾诉 0.9 / 知识决策 0.55 / 格式任务 0.2 |
| 进度感知强度调度 | PIS | 开头强（立基调）→ 中段稳 → 尾段 0.55 渐弱自然收尾 |
| 在线质量纠正 | OQC | AI 腔三通道抑制 + 情感缺失检测 + 角色漂移拉回锚点 |

**五个正交通道（表达层）**：DMR 稠密乘性重加权 / KV 情感调制 / 锚点 tanh 加性 / AI 腔三通道抑制 / DSA 动态方向。

**角色感知锚定（v6.5+）**：`v_target = 0.7·v_角色 + 0.3·v_用户`，角色基调跨轮稳定。
**高唤起正性模板抑制（v6.5~v6.7）**：低唤起角色（前辈/老师/兄长/毒舌/老人）遇用户开心时不被"太好了！"模板劫持。
**身份暴露硬拦截（v6.2）**：全文任意位置出现身份打开器 → 持久拦截至句界。

## 2. 优点

- **全家族最强**：5 大基准综合 **0.7046**，超 P5（0.6255）**+12.6%**，全模式第一；
- **维度级大跳变**：LLM-Judge 对真人胜率 0.667（+122%）、HEART-BENCH 综合 0.5217（+63%）、情感推理质量 0.78（+39%）、EmoCharacter 匹配 fidelity 0.8425（全模式最高）；
- **零权重万能插件**：不修改任何权重，任何已部署模型即插即用；
- **跨模型泛化已验证**：Qwen2.5-1.5B +233%、Qwen2.5-3B +80%、Qwen3-1.7B +67%（Qwen3 评分 3.92 超真人均值 3.90）；
- **角色稳定性**：EmoCharacter 3-run 真实一致性 0.900（std=0.0），三轮随机种子结果完全一致；
- **性能开销 <7%**：19.7 tok/s（裸 20.1）、峰值显存 3.78GB 与裸持平；
- **迭代成果扎实**：v6.5~v6.7 修复"太好了！"模板劫持（兄长 0.8→0.95、老师 0.8→0.9）。

## 3. 缺点与局限

- **仍属解码期注入家族**：需要能访问 logits/KV 的推理环境（非训练态，模型权重不永久改变）；
- **1.5B 基座天花板**：EmoCharacter 一致性 0.900 vs P5 单 run 0.93（-0.6%，噪声内）——小模型表达力仍是上限；
- **角色扮演胜率依赖模板抑制**：模板劫持是持续要防的敌人（迭代型维护成本）；
- **多模型评测样本有限**：泛化验证 3 模型 × 部分基准，未全量铺开。

## 4. 适用场景

- **任何已部署对话模型的"即插即用"情感升级**（不改权重、不改前奏）；
- 角色扮演 / 情感陪伴 / 情感倾诉类产品（EmoCharacter 0.8425 全模式最高）；
- 多模型统一接入（同一解码器插件跨架构生效）；
- 对"零权重、可审计"有要求的合规场景。

## 5. 不适用场景

- 需要**永久改变模型行为**（离线模型文件）的场景（应选 P6 LoRA 训练态）；
- 完全无 logits 访问的极受限 API（需降级）；
- 追求"训练态一致性"而非"推理期插件"的交付形态。

## 7. 边际效益分析

- **组合机制的跳跃式边际**：TAD/PIS/OQC 三导演 + 五通道的组合带来 +12.6% 的跳跃式提升（相对 P5），远大于单通道调参的边际——**架构级组合 > 参数级调优**；
- **版本迭代的边际递减**：v6.5→v6.7 模板劫持修复是"补丁级"边际（0.8→0.95→0.9），提升幅度越来越小，进入收敛区；
- **多模型泛化的边际递减**：1.5B +233% → 3B +80% → Qwen3 +67%——越大的基座，插件的相对边际越小（基座本身更强）；
- **残差边际**：EmoCharacter 一致性 0.9 vs 0.93 的差距说明小模型天花板的残差边际难以靠插件突破。
