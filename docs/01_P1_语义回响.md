# P1 语义回响（Semantic Echo, SE）

> **一句话**：在表示空间（hidden_state）里做"情感底色注入"——开山之作，证明"让 AI 先处在某种情感状态，再自然表达"这一思路可行。
> **操作空间**：表示空间（forward hook 捕获 hidden_state）｜ **改权重**：否（钩子注入）｜ **代表成果**：语义熵 +17.9%~+45%，E1~E13 全套验证，两篇论文。

---

## 1. 核心机制

1. forward hook 捕获模型最后 N 层 hidden_state；
2. 情感筛选（情感词库打分）后把"情感句子"入池；
3. 池质心 `@` 随机投影矩阵（933MB），得到情感偏置向量；
4. `logits += 偏置 × λ`（λ 为注入强度，升级版加入思考链中断）。

核心思想：**情感先于表达**——不是教模型"说情感词"，而是让它在底层先"处在某种情感状态"。

## 2. 优点

- **开山验证**：E1~E13 分批完整验证"情感向量注入"有效，λ 扫描出现经典的倒 U 型曲线；
- **细腻度提升显著**：λ=0.5 时细腻度 **+17.9%**，语义熵 +17.9%~45%（0.5B 上）；
- **情感命中率提升**：情感词库筛选 + 思考阶段分离后，命中率 0.23→0.40；
- **保留策略成熟**：E13 全局保留最稳（熵 1.9372 / 命中 0.22）；
- **论文沉淀**：《语义回响 1.5B 情感表达增强与图灵测试实证研究》《决策的温度》两篇成文；
- **基建复用**：交付 9 模块 semantic_echo 包（回响池/情感过滤器/回响评估器/采样处理器/翻译毒药），被 P1.5~P6 全部复用。

## 3. 缺点与局限

- **必须本地权重**：依赖 forward hook，闭源 API 完全不可用；
- **跨尺度灾难性坍缩**：从 0.5B 迁移到 1.5B/7B 时重复率飙到 83%~98%（负样本直接催生了 P1.5）；
- **Qwen3 系高度敏感**：对注入极度敏感，易坍缩；
- **内存大**：随机投影矩阵 933MB，是 P3 打分表（3.6MB）的 259 倍；
- **λ 归一化缺失**：跨模型 λ 需要人工归一化。

## 4. 适用场景

- 本地自托管 0.5B~1.5B 模型的**情感底色增强**（情感浓度、细腻度优先）；
- 学术研究：验证"表示空间注入"这一机制本身；
- 作为 P1.5 的底座（先跑通机制，再谈自动适配）。

## 5. 不适用场景

- **任何闭源 API / 云上模型**（无 hook 可用）；
- **Qwen3 系 / 3B 以上大模型**（易坍缩，需 P1.5 因子修复）；
- **需要长上下文稳定输出**的严肃任务（512+ tokens 坍缩未解决）；
- 生产级低风险部署（坍缩代价高）。

## 6. 跑分效果

**G 统一基准**（2026-08-10，种子 2026，Qwen2.5-1.5B fp16，7B 裁判，30 样本）：

| 模式 | win_rate | 熵 | 重复率 | 情感命中 | 长度(字) |
|---|---|---|---|---|---|
| 裸 | 0.1167 | 1.4840 | 0.0102 | 0.1601 | 115.7 |
| **P1 语义回响** | 0.0500 | 0.9931 | **0.4824** | 0.0900 | 341.0 |

> 注意：在 1.5B 上 P1 裸注入出现**熵坍缩 + 重复率暴涨**——这正是它需要 P1.5 适配的实证。

**2026 全流程 5 基准**（综合 0.6063，当年次席）：

| HeartBench | HEART-BENCH | LLM-Judge | TuringBench | EmoCharacter | **综合** |
|---|---|---|---|---|---|
| 0.4682 | 0.5873 | 0.2266 | 0.9333 | 0.8162 | **0.6063** |

**P1 自己的关键实验**（0.5B）：λ=0.5 细腻度 +17.9%；E9 命中率 0.23→0.40；E13 熵 1.9372 / 命中 0.22。

## 7. 边际效益分析（冰心效应 = 边际收益递减）

- **λ 的倒 U 型**是教科书级的边际收益递减：λ=0.1→0.5 增益递增（边际收益为正），λ>0.5 后增益消失甚至反噬（边际收益为负）——"剂量效应而非开关"；
- 情感词库筛选：第 1 轮筛选命中率 0.23→0.40（+74%），后续轮次提升迅速收窄；
- **跨尺度迁移的边际效益为负**：同样参数从 0.5B 搬到 1.5B 直接坍缩，说明该机制的边际收益强依赖模型尺度。
