# P2.5 情感潮汐解码 ETD（Emotion Tidal Decoding）

> **一句话**：在**概率空间**做乘性重加权——数学上不可能坍缩，且不依赖模型内部，闭源 API 也能用。
> **操作空间**：概率空间｜ **改权重**：否｜ **代表成果**：潮汐回响混合（P1×P2.5）v4.2 LLM-Judge **+91%**、v8+人设 0.5167。

---

## 1. 核心机制

三层结构：
1. **感知层**：外部 VAD 文本测量（cnsenti 情感强度）+ 会话轨迹"潮汐"；
2. **决策层**：共情目标 + 自适应引导强度 α；
3. **表达层**：采样分布乘性重加权 `p' ∝ p^(1-α) · q_emo^α`（对 logits 做有界重加权）。

迭代里程碑：v4 AI 腔三通道抑制 → v6 身份拦截 + 句子硬停止 → v8 人设系统提示 + 多候选自选（N=3/5）。
**潮汐回响（回响×潮汐混合）= P1 × P2.5**，由混合注入器实现。

## 2. 优点

- **数学上不可能坍缩**：概率重加权有界，重复率 0；
- **不依赖模型内部**：外部文本感知即可，**闭源 API 可用**；
- **叠加增益最猛**：潮汐回响混合 v4.2 LLM-Judge **+91%**（0.1833→0.35）；v8+人设 N5 **0.5167（+48%）**；
- **多模型横向全正**：1.5B 混合 +87.5%、3B 潮汐 +33%；
- **人设/AI腔抑制沉淀**：v6 身份拦截、AI 腔三通道抑制后来被 P6 继承。

## 3. 缺点与局限

- **词库稀疏**：网络流行语等新词识别弱；
- **通用"人味儿"反作用**：HeartBench 类"自主性"任务 -9.4%（情感任务专用）；
- **混合方案限 Qwen2 系**：潮汐回响混合在其他架构上未验证；
- 胜率天花板受制于 1.5B 表达力。

## 4. 适用场景

- **情感倾诉 / 共情陪伴**类任务（EmoCharacter 一致性 0.6→0.8）；
- 闭源 API 场景（唯一可用的概率空间方案）；
- 与 P1 叠加（潮汐回响混合）获得双空间增益。

## 5. 不适用场景

- 需要"自主性/决策"维度的通用助手任务（HeartBench 反作用）；
- 需要稳定口语化网络表达的对话（词库稀疏）；
- 追求"人味通用性"而非"情感浓度"的任务。

## 7. 边际效益分析

- **版本迭代边际递减**：v4→v6→v8 单版本提升从 +91%（v4.2，相对 v3 的跳跃）逐步收窄到 +48%（v8，相对 v4.2 后）；
- **多候选 N 的边际**：N=3→N=5 提升明显小于 N=1→N=3（选优饱和）；
- **α 引导强度**：α 过大压缩多样性、过小无效果，存在"甜蜜点"，两侧边际收益都为负。
