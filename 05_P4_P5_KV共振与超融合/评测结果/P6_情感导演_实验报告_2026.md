# P6 情感导演解码（EDD）实验报告

> 提交日期：2026-08-11 ｜ 模型：Qwen2.5-1.5B-Instruct ｜ 种子：2026
> 定位：零权重万能插件（解码期注入，不修改任何模型权重）

---

## 一、方案一句话

**P6 EDD（Emotional Director Decoding，情感导演解码）**：在解码期注入"情感导演"信号，用
任务自适应强度（TAD）+ 进度感知强度调度（PIS）+ 在线质量纠正（OQC）三个导演层机制，
叠加 DMR 稠密乘性重加权 / KV 情感调制 / 锚点 tanh 加性 / AI 腔三通道抑制 / DSA 动态方向
五个正交通道，实现对任意对话模型的零权重情感增强。与 P 系列前辈（P1~P5）同属零权重
解码期注入家族；T1（训练态微调外挂）已归档另册。

## 二、核心机制（全部零权重）

| 机制 | 缩写 | 作用 |
|---|---|---|
| 任务自适应强度 | TAD | 探测任务类型：角色扮演 1.25 / 情感倾诉 0.9 / 知识决策 0.55 / 格式任务 0.2 |
| 进度感知强度调度 | PIS | 开头强（立基调）→ 中段稳 → 尾段 0.55 渐弱自然收尾 |
| 在线质量纠正 | OQC | AI 腔三通道抑制 + 情感缺失检测 + 角色漂移拉回锚点 |
| 角色感知锚定 | v6.5+ | `v_target=0.7·v_角色+0.3·v_用户`，角色基调跨轮稳定 |
| 高唤起正性模板抑制 | v6.5~v6.7 | 低唤起角色（前辈/老师/兄长/毒舌/老人）遇用户开心时不被"太好了！"模板劫持 |
| 身份暴露硬拦截 | v6.2 | 全文任意位置出现身份打开器 → 持久拦截至句界 |
