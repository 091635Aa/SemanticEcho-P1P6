# 第五套方案：KV 情感共振解码（KV-Emotion Resonance Decoding, KER / P5）

> 版本：2026-08-10 v1.0 ｜ 定位：**注意力缓存空间 · 只读接口调制 · 解码期引导**
> 承接 P1（语义回响/表示空间）、P2（通用兼容层/配置空间）、P3（情感潮汐/概率空间）、P4（锚点回响/嵌入空间）

---

## 一、灵感从哪来（扫描四前辈后的新观察）

| 架构 | 操作空间 | 操作对象 | 一句话本质 | 边界 |
|---|---|---|---|---|
| P1 语义回响 | 表示空间 | hidden_state | 让模型"回想自己的情感再表达" | 随机投影不可解释、933MB 矩阵、依赖 hook |
| P2 通用兼容层 | 配置空间 | 参数表 | 每个模型用多大强度 | 本身不注入 |
| P3 情感潮汐 | 概率空间 | logits 分布 | 采样时涌向情感目标（乘性有界） | 词表稀疏（千级），OOV 无法引导 |
| P4 锚点回响 | 嵌入空间 | 词表权重 W_e | 用模型自己的情感语义地图做稠密打分 | 方向静态、加性注入 |

**新观察（P5 的灵感）**：P1-P4 全部在"**模型输出什么**"上做文章（logits / 概率 / 参数 / 打分表）。
但没有一套方案碰过"**模型看什么**"——**注意力本身**。

模型生成每个 token 时，注意力头在 KV 缓存上决定"此刻想什么"：
- 如果模型把更多注意力投给对话中**情感强的 token**（"我好难受""我怕""我好开心"），
  它下一句就更可能"走心"地回应情绪；
- KV 缓存（key/value）是标准接口（`past_key_values`），**不需要修改任何权重**、
  不读 hidden_state 之外的内部结构、一切 HF 模型天然暴露。

于是：**P5 ＝ 在注意力缓存空间（第五个空间）做情感调制**——
用 P4 的稠密打分表在缓存里**定位情感 token**，对它们的 key（及可选 value）
做有界缩放，让模型的注意力**向对话中的情感内容共振**。

> **一句话主张**：P1-P4 引导"模型说什么"，P5 引导"模型看什么"——注意力共振，
> 使情感"看见"即"表达"。不写权重、不改 logits、全词表定位、兼容一切暴露 KV cache 的模型。

---

## 二、与 P1-P4 的本质区别（底层不同）

1. **操作空间不同（第五个空间）**：P1 表示空间 → P3 概率空间 → P4 嵌入空间 →
   **P5 注意力缓存空间（KV cache）**。P5 不在 logits 上注入、不在概率上重加权，
   而是改变注意力权重分配——softmax 归一化使调制**天然有界**，机制上不可能坍缩。
2. **情感来源不同**：P5 的情感方向由**外部 VAD（P3 感知）+ 模型自身内心（P1 融合）**
   共同决定（`v_eff`），但作用点从"输出分布"移到"注意力缓存"。
3. **载体不同**：P4 用静态打分表直接抬升 logits；P5 用同一张打分表**定位情感 token 位置**，
   再在缓存里调制——打分表从"输出偏置"升级为"注意力导航图"。

## 三、总体架构（三层，结构参考 P3）

```
┌──────────────────────────────────────────────────────────────┐
│               KV 情感共振解码引擎（KER / P5）                     │
│                                                                │
│  ① 感知层：潮汐感知器（复用 P3）                                  │
│     输入：用户消息 → VAD 测量 + 会话情感轨迹                       │
│                                                                │
│  ② 决策层：目标决策器（复用 P4）+ P1 融合 + P2 自适应               │
│     输入：VAD / 思考链 / 指令 / 模型内心 hidden_state（P1）        │
│     输出：v_eff ∈ R^K（外部目标 × 内心状态）、调制强度 κ（P2 自适应）│
│                                                                │
│  ③ 表达层：KV 情感调制器（新）                                    │
│     定位：g(p) = S[token_p]·v_eff（P4 稠密打分表，全词表覆盖）      │
│     调制：K_l[:,:p,:] *= (1+κ·clip(g,0,1))  → 情感 token 注意力共振│
│           V_l[:,:p,:] *= (1+κ_v·clip(g,0,1))（可选，情感记忆放大）  │
│     在线兜底：重复率/熵监测 → κ 减半/归零                          │
└──────────────────────────────────────────────────────────────┘
```

### ① 感知层（复用 P3）
`潮汐感知器.测量(用户消息)` → 情感状态 V=(valence, arousal, dominance) + 轨迹。

### ② 决策层（复用 P4 目标决策器 + P1 内心状态 + P2 自适应）
- `v_target`：复用 `目标决策器.计算目标()`（VAD→锚点映射、共情公式、多源融合）；
- **P1 融合（内心状态）**：轻量只读 hook 捕获最后一层 hidden_state h_t，
  `v_dyn[k] = cos(h_t, e_k)`，`v_eff = normalize((1-γ)·v_target + γ·v_dyn)`
  —— 情感方向 = 外部目标 × 模型此刻内心（先感受到，再表达）；
- **P2 自适应（强度）**：
  `κ = κ基 × (1+Δarousal) × min(1, 活跃度×2.5)`，封顶 `κ上限`；
  未注册模型走保守 κ=0.1；量化 4bit ×0.75。

### ③ 表达层：KV 情感调制（核心公式）
设当前 KV 长度为 T，情感方向 v_eff ∈ R^K（L2 归一化）：

```
① 稠密情感定位（P4 打分表 S ∈ R^{V×K}）：
   g(p) = S[token_p] · v_eff ∈ [-1,1]          # 每个位置的情感强度
   clip 到 [0,1]（只放大正向情感 token）

② key 调制（情感注意力共振）：
   K_l[:, :, p, :] *= (1 + κ · clip(g(p), 0, 1)),  l ∈ 最后 L 层
   ⇒ Q·K^T 中情感位置 logits 抬升 → softmax 后注意力权重更大
   ⇒ 模型"更关注对话里的情感内容"，天然有界（softmax 归一化）

③ value 调制（可选，情感记忆放大）：
   V_l[:, :, p, :] *= (1 + κ_v · clip(g(p), 0, 1))
   ⇒ 情感 token 携带的信息更强地流入后续表示
```

**为什么安全**：注意力权重经 softmax 归一化，key 缩放只会**重分配**注意力
（情感 token 多分一点、其他少分一点），输出是 V 的加权和，数学上有界；
κ 取值小（0.1~0.3）+ 在线退化兜底（重复率/熵异常 → κ×0.5，连续 3 次 → κ=0）。

**与 P4 的正交性**：P4 改 logits（输出分布），P5 改注意力（输入侧聚焦），
两者作用在不同环节，可叠加（P4+P5 = 既"看得到"又"说得出"情感）。

## 四、混合方案（把 P1+P2 混起来，参考 P3 结构）

P5 的混合不是"加性叠加通道"，而是**三处融合进一条链路**：

| 融合点 | 来自 | 在 P5 中的角色 |
|---|---|---|
| 感知层 | P3（潮汐感知器） | 外部情感认知（VAD + 轨迹） |
| 决策层·方向 | P4（目标决策器）+ **P1（内心 hidden_state）** | v_eff = 外部目标 × 模型内心 |
| 决策层·强度 | **P2（通用兼容层）** | κ 自适应（扫描表/公式/架构族因子） |
| 表达层·载体 | **P4（稠密打分表）** | 情感 token 定位（注意力导航图） |
| 表达层·动作 | **新（KV 调制）** | 注意力共振 |

P3 的三层结构（感知/决策/表达）是"如何把情感工程搭起来"的骨架，P5 沿用；
P1 的自我回响思想（情感先于表达）是"情感方向从哪来"的源头，P5 用 DSA 混入；
P2 的自动适配是"每个模型用多大强度"的答案，P5 的 κ 直接走这套体系。

**可叠加通道（默认关，评测时开）**：
- P4 锚点 logits 注入（`logits += β·tanh(S@v_eff/T)`）——与 KV 调制正交；
- P3 稀疏潮汐偏置 / P1 回响池——全开即四通道，但 P5 单模式纯净优先验证。

## 五、兼容性（"兼容所有模型"）

| 能力 | P5 的满足方式 |
|---|---|
| 不修改模型权重 | ✅ 全部调制作用于运行时 KV 缓存，权重零写入（`sum`/`data_ptr` 断言可选） |
| 标准接口映射 | ✅ 只用 `get_input_embeddings()`（打分表）+ `past_key_values`（KV 调制） |
| 任意 HF 模型 | ✅ Qwen/Llama/Mistral/Gemma/Phi 等均暴露 `past_key_values`；不暴露则自动降级为纯采样 |
| 闭源 API | ⚠️ KV 调制需本地缓存；可降级为「P4 三级链路」或纯提示模式（P5 主打本地通用） |
| 不读隐藏状态 | ✅ 可选（关闭 DSA 即不读 hidden_state，仅用外部 VAD + 打分表） |

## 六、实验计划

1. **E1 单模型对照**（Qwen2.5-1.5B）：裸 / 锚点P4 / 超融合DMR / **P5 KER** / **P4+P5 叠加**，
   同提示词、**每模式不同种子**（用户要求），指标：熵/重复率/情感命中/长度/样例；
2. **E2 参数扫描**：κ ∈ {0.05, 0.1, 0.2, 0.3} × 调制层数 ∈ {2, 4, 8}，找熵不塌且命中最大；
3. **E3 LLM-Judge**：30 条样本配对盲评（本地 7B），P5 vs 裸 vs 锚点P4；
4. **E4 叠加验证**：P4+P5 双通道是否优于任一单通道（正交性检查）。

## 七、风险与对策

| # | 风险 | 对策 |
|---|---|---|
| 1 | key 缩放过度 → 注意力失真 | κ 保守（≤0.3）+ 在线兜底（κ 减半/归零）+ E2 扫描 |
| 2 | 只放大正向情感，负向情感被忽略 | v_eff 极性决定放大哪个方向；负向情感（v_target 负）同样命中"难过/愤怒"锚点 token |
| 3 | KV 调制对第一生成 token 无影响 | 首 token 之后即生效；首 token 影响可忽略（解码器普遍现象） |
| 4 | 无 KV 暴露的模型 | 自动降级（`past_key_values is None` → 与裸一致）；配 P4 三级链路兜底 |
| 5 | 与 P4 叠加后过强 | 叠加时 κ×0.5、β×0.5 起步，E4 消融验证 |
