# 历史数据整理说明

> 本目录汇总语义回响项目的历史**训练数据**与**实验数据**，作为最终报告的支撑材料。
> 数据复制自 `f:\lora外挂` 与 `i:\Desktop\语义回响\实验数据`，全部为原始文件，未做删改。

---

## 目录结构

```
历史数据/
├── 训练数据/            ← 情感/温柔数据集 + 训练脚本
│   ├── emotion_dataset.jsonl   情感数据集（LoRA 训练用）
│   ├── gentle_dataset.jsonl    温柔风格数据集
│   └── 训练脚本/
│       ├── gen_dataset.py          数据集生成器
│       ├── train_lora.py           基础 LoRA 训练
│       ├── train_emotion_lora.py   情感 LoRA 训练（Qwen3-4B / 7B）
│       └── train_emotion_think.py  带思考链的情感 LoRA（emotion_qwen3_4B_think）
├── LoRA适配器/          ← 5 个历史训练产物（适配器权重）
│   ├── emotion_7B/            Qwen2.5-7B 情感适配器
│   ├── emotion_qwen3_4B/      Qwen3-4B 情感适配器
│   ├── emotion_qwen3_4B_think/ Qwen3-4B 思考链情感适配器（融合测试用）
│   ├── emotion_v1/            情感适配器 v1（早期）
│   └── gentle_v2/             温柔风格适配器 v2
└── 实验数据/            ← 全链路/多模型/思考链/E 系列实验原始结果
    ├── 全链路验证/       已注册(Qwen3-4B) vs 未注册(DeepSeek-7B) 端到端验证
    ├── 多模型对照/       19 配置多模型对照 + Qwen3 通用注入重测 + 思考链中断 + LoRA 融合
    ├── 可视化/           实验图表（箱线图/热力图/雷达图/柱状图等）
    └── E1~E13.json        早期系列实验原始结果 + 汇总
```

## 1. 训练数据

| 文件 | 内容 | 用途 |
|---|---|---|
| emotion_dataset.jsonl | 情感对话样本（instruction/response 对） | 情感 LoRA 训练 |
| gentle_dataset.jsonl | 温柔风格对话样本 | gentle_v2 适配器训练 |
| 训练脚本/ | 数据集生成 + 三类 LoRA 训练脚本 | 训练复现 |

| 适配器 | 基座 | 特点 | 实验引用 |
|---|---|---|---|
| emotion_7B | Qwen2.5-7B | 情感适配器 | 早期情感测试 |
| emotion_qwen3_4B | Qwen3-4B | 情感适配器 | 融合测试基础版 |
| emotion_qwen3_4B_think | Qwen3-4B | 保留思考链（enable_thinking） | LoRA+思考链融合测试（四组同种子） |
| emotion_v1 | — | 情感适配器 v1 | 早期迭代 |
| gentle_v2 | — | 温柔风格 v2 | 温柔语态实验 |

## 3. 实验数据

### 3.1 全链路验证（2026-08-06）
- `Qwen3-4B_4bit_全部_20260806_185940.{json,jsonl,csv}`：已注册模型全套测试（裸+回响，runs=5）
- `全链路_DeepSeek_DeepSeek-R1-Distill-Qwen-7B_210529.json`：未注册模型全套测试（裸+回响+思考链纠正，兜底 λ=0.045）

### 3.2 多模型对照
- 19 配置：Qwen2.5（0.5B/1.5B/3B/7B）、Qwen3（0.6B/1.7B/4B）、SmolLM2-1.7B、gemma-2-2b、Phi-3.5-mini × fp16/4bit
- `Qwen3通用注入/`：通用注入值重测（6 配置）
- `思考链中断/`：三组同种子对比 + LoRA 融合 v2 测试

### 3.3 可视化

### 3.4 E 系列（早期实验）
