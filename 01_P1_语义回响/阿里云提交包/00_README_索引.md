## 三、30 秒速读

1. **原理**：回收被 softmax 丢弃的 token 嵌入 → 情感池 → 投影注入 logits（×λ），
   让 1.5B 输出带上"情绪底色"。
2. **结果**：TuringBench 人似度翻倍（0.23→0.47），4/5 项图灵基准反超裸基座。
3. **通用**：V3 自适应匹配，任意模型输入 hidden_dim 自动推荐最优 λ/γ/τ；
   19 配置实测 + 未注册模型兜底不劣于定制。
4. **生产**：V3 自带 FastAPI（自定义协议 + OpenAI 兼容）+ 控制面板 + 打标闭环，
   长上下文 2048 tokens 稳定（重复率≈0）。
5. **落地**：1.5B 4bit 仅需 ~1.3GB 显存，情感陪伴场景成本可降至大模型 API 的 1/30~1/300。
