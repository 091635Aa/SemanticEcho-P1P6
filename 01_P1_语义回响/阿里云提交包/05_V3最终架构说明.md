## 二、全模型自适应匹配（核心：适配全部模型）

```python
推荐参数(hidden_dim)：
    命中扫描表（896/1536/2048/3584）→ 直接用实测最优 (λ, γ, τ)
    未命中 → 分段公式兜底：
        λ = 0.5 × (896/hidden)^1.5        # hidden < 2048
        λ = 0.28 × (896/hidden)           # hidden ≥ 2048
        γ = 0.05 × (hidden/896)^0.5
        τ = 0.10 × (896/hidden)^0.5       # 修正：随 hidden_dim 缩放
```

| 1536 | Qwen2.5-1.5B | (0.08, 0.07, 0.09) | 推荐命中 0% |

> **结论**：任何模型只要给出 hidden_dim，无需人工调参即可获得可用参数。

## 三、推理框架（四层自动编排）

```
推理框架(hidden_dim, vocab_size)
  → 推荐 λ/γ/τ（扫描表/公式 + 归一化基准）
  → 动态策略 v2：jieba 分词检测情感密度，
      密度 > 0.15 → 策略B：降τ不升λ / 策略C：λ+0.02 且 τ→0.05
  → RAG：FAISS 检索 top-k 拼接 [参考信息] 前缀（向量库缺失自动回退）
  → LoRA：peft 热切换（挂载/卸载，失败自动回退基座）
  → 回响：长上下文走 λ 步数衰减，否则标准回响
  → 在线指标：熵 / 重复率 / 情感命中率 / 池统计
```

## 四、回响引擎 —— λ 步数衰减（长上下文稳定）

前 256 步保持 λ，之后**线性衰减到 0.3λ**（生成结束时到达）——
解决长文本后期注入累积导致的坍缩复读。

**实测（3B 4bit，2048 tokens，4 区间）：**

| 配置 | 开心·区间 1024-2048 熵 | 开心·重复率 | 判定 |
|---|---|---|---|
| 固定 λ（无衰减） | 0.016 | 0.985 | ❌ 崩死复读 |
| **λ 步数衰减（激进）** | **5.30** | **0.000** | ✅ 全程稳定 |

悲伤/中性同结论：衰减方案 4 区间熵全程 2.4~5.3、重复率≈0。
（数据：`数据/长上下文_稳定_2048.csv`）
