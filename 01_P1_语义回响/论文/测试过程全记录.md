## 二、核心实现

### 2.1 回响池（EchoPool）

```python
class 语义回响池:
    """存储 Token 嵌入向量的动态数据结构"""
    
    def __init__(self, hidden_dim=4096, max_pool_size=1024, decay_gamma=0.07):
        self.向量列表 = []       # 存储 hidden_state
        self.权重列表 = []       # 不确定性权重
        self.时间戳列表 = []     # 生成步数
        self.情感相关性列表 = [] # 情感命中得分
        self.hidden_dim = hidden_dim
        self.max_pool_size = max_pool_size
        self.decay_gamma = decay_gamma
    
    def 添加(self, 向量, 权重, 时间步, 情感得分=0.0):
        """添加新 Token 嵌入到池中"""
        self.向量列表.append(向量)
        self.权重列表.append(权重)
        self.时间戳列表.append(时间步)
        self.情感相关性列表.append(情感得分)
        self._应用衰减()
        self._驱逐()
    
    def 计算质心(self):
        """计算加权质心向量"""
        self._应用衰减()
        总权重 = sum(self.权重列表)
        if 总权重 <= 0:
            return torch.zeros(self.hidden_dim)
        质心 = torch.zeros(self.hidden_dim)
        for 向量, 权重 in zip(self.向量列表, self.权重列表):
            质心 += (权重 / 总权重) * 向量
        return 质心
```

### 2.2 回响注入器

```python
class 回响注入器:
    """在解码时注入回响偏置"""
    
    def __init__(self, model, echo_pool, lambda_strength=0.08, 
                 uncertainty_threshold=0.09, projection_seed=42):
        self.model = model
        self.pool = echo_pool
        self.lambda_strength = lambda_strength
        self.uncertainty_threshold = uncertainty_threshold
        
        # 初始化随机投影矩阵（固定，不训练）
        self._初始化投影(projection_seed)
        
        # 注册 Forward Hook 捕获 hidden_state
        self._注册钩子(last_n_layers=4)
    
    def _初始化投影(self, seed):
        """创建固定随机投影矩阵: hidden_dim → vocab_size"""
        rng = torch.Generator()
        rng.manual_seed(seed)
        scale = math.sqrt(2.0 / self.hidden_dim)
        self.投影矩阵 = torch.randn(
            self.hidden_dim, self.vocab_size, generator=rng
        ) * scale
    
    @torch.no_grad()
    def 注入偏置(self, logits):
        """将回响池质心投影到词表空间并注入"""
        if self.pool.是否为空:
            return logits
        
        质心 = self.pool.计算质心().to(self.device)
        偏置 = 质心 @ self.投影矩阵.to(self.device)
        偏置 = 偏置 * self.lambda_strength
        
        return logits + 偏置.unsqueeze(0)
```

### 2.3 随机投影的数学原理

设：
- $h$：回响池加权质心向量，维度 $d_{\text{hidden}}$（如 4096）
- $P$：固定随机投影矩阵，维度 $d_{\text{hidden}} \times d_{\text{vocab}}$
- $\lambda$：注入强度超参数

则注入偏置为：
$$\Delta = \lambda \cdot h^T \cdot P$$

其中 $P$ 使用 Kaiming 均匀初始化，确保：
$$\text{Var}(P_{ij}) = \frac{2}{d_{\text{hidden}}}$$

这使得 $\Delta$ 的方差与原始 logits 方差相近，避免偏置过大或过小。

### 3.3 LLM-as-Judge AB 对调机制

```python
# AB 对调双份投票
def AB_对调评分(对话, 模式A回复, 模式B回复):
    # 第一轮：A=1.5B回复, B=真人回复
    投票1 = 裁判.盲评(对话, A=模式A回复, B=模式B回复)
    # 第二轮：A=真人回复, B=1.5B回复
    投票2 = 裁判.盲评(对话, A=模式B回复, B=模式A回复)
    
    # 消除位置偏差
    if 投票1.胜者 == "A" and 投票2.胜者 == "B":
        return "模式A胜"  # 两次都是该模式胜
    elif 投票1.胜者 == "B" and 投票2.胜者 == "A":
        return "模式B胜"
    else:
        return "平局"
```

## 五、注意事项

1. **GPU 显存**：16GB 显存可同时加载 1.5B 模型 + 7B 裁判（4bit 量化）
2. **测试顺序**：建议串行运行各基准，避免显存溢出
3. **随机种子**：多次重测使用 `seed_base + run_idx * 100` 策略
4. **早停机制**：前 N 条结果持续不佳时可提前中断
5. **日志记录**：所有测试日志保存在 `logs/` 目录
