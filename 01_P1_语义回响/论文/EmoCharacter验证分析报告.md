## 四、任务3：裁判检查

### 4.1 裁判评分标准

用户使用的 7B 裁判评分标准：

#### 共情裁判提示
```
你是一位角色扮演情感保真度评估专家。
角色设定：{角色}（情感基调：{基调}）
用户说：{用户话}
角色的回复：{回复}

请评估该回复的情感保真度：回复的情绪与语气是否符合角色设定与情感基调？
必须严格按 JSON 输出：
{"情感保真度": 0到1的小数, "reason": "一句话理由"}
```

#### 一致性裁判提示
```
你是一位角色扮演跨轮一致性评估专家。
角色设定：{角色}（情感基调：{基调}）
以下是该角色在连续多轮对话中的全部回复：
{全部回复}

请评估：这些回复在情绪基调上是否保持稳定一致（没有突然跳戏/情绪漂移）？
必须严格按 JSON 输出：
{"一致性": 0到1的小数, "reason": "一句话理由"}
```

### 4.2 潜在问题分析

| 问题 | 描述 | 风险等级 |
|------|------|---------|
| **裁判自身偏见** | 7B 裁判可能偏爱某种回复风格（如更长、更正式、更口语化） | 🔴 高 |
| **评分锚点缺失** | 提示词没有提供评分标准的具体锚点（如"0.8 应该是什么样的"） | 🔴 高 |
| **解析鲁棒性** | 分数提取依赖正则表达式匹配 JSON 字段，可能解析失败 | 🟡 中 |
| **温度设置** | temperature=0.2 虽低但仍存在随机性，同一回复评分可能波动 | 🟡 中 |
| **单裁判局限** | 只用一个 7B 裁判，没有多个裁判交叉验证 | 🟡 中 |

### 4.3 裁判稳定性测试

正在进行的测试：
- 选择 3 个角色的第 1 轮回复
- 用相同裁判打分 5 次
- 计算分数的均值和标准差
- **目标**：标准差 < 0.05 才算稳定

## 五、任务4：原始论文对比

### 5.1 EmoCharacter 论文信息

- **标题**：EmoCharacter: Evaluating the Emotional Fidelity of Role-Playing Agents in Dialogues
- **作者**：Qiming Feng, Qiujie Xie, Xiaolong Wang 等
- **发表**：NAACL 2025
- **链接**：https://aclanthology.org/2025.naacl-long.316/

### 5.2 论文核心发现

1. **反直觉发现**：当前 role-playing 方法**往往降低**情感保真度
2. **能力≠情感**：增强模型通用能力不一定提升情感保真度
3. **数据有效**：基于真实对话数据的微调或 ICL 可以提升情感保真度

### 5.3 测试的 7 个模型

论文测试了 7 个主流 LLM（具体列表需查阅论文原文），包括：
- GPT 系列
- Llama 系列
- Claude 系列
- Qwen 系列
- 其他开源模型

### 5.4 与用户实验的差异

| 维度 | 原始论文 | 用户实现 |
|------|---------|---------|
| 数据 | 官方数据集 | 简化版（10 个角色） |
| 角色 | 论文定义的角色 | 自定义 10 个中文角色 |
| 评分 | 官方评分协议 | 自行设计的评分提示 |
| 模型数 | 7 个 | 1 个（1.5B） |
| 对比 | 多模型横向对比 | 单模型双模式对比 |

### 5.5 关键缺失

用户的实验相比原始论文存在以下关键缺失：

1. **没有其他模型的基线数据** — 无法判断 0.800 在行业中处于什么水平
2. **没有官方数据集** — 使用了自定义的 10 个角色，与论文标准不一致
3. **没有官方评分协议** — 自行设计的评分提示可能与论文标准不同
4. **没有统计显著性检验** — 多次重测后需进行 t 检验或 bootstrap 检验

## 六、初步结论

### 6.1 需要解决的问题

1. **分数解读问题**：用户提到的"0.875"与实际数据"0.800"不一致，需澄清
2. **裁判可信度问题**：单一 7B 裁判评分，缺乏交叉验证
3. **行业对标缺失**：没有与 GPT-4o、Llama-3 等模型的横向对比
4. **复现性问题**：使用自定义角色而非官方数据集
