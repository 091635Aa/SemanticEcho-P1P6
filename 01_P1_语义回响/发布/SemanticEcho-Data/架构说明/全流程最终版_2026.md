## 一、定位：颠覆性 AI 扮演架构

传统 AI 扮演依赖「提示词告知 + 外挂记忆 + 角色预训练」——临时搭台唱戏，扮演是**表层符号**的，脆弱、漂移、不一致。

本架构让扮演发生在**模型底层**：通过第 0 层**直接调整模型本身**（训练期权重级改造），让模型**遗忘 AI 身份**、内化身世与说话风格——模型从底层就是那个角色，而非扮演那个角色；第 1 层再叠加即时情感注入，实现完整的底层拟人。

## 二、五层架构总览

```
第0层  模型底层（直接调整模型本身）          ← 新增·颠覆核心
第1层  语义回响（思考链中断 + 总体向量注入）  ← 即时情感状态
第2层  LoRA                                 ← 风格外挂（可选）
第3层  RAG                                  ← 知识检索
第4层  外挂记忆                             ← 对话历史记忆
```

| 层 | 定位 | 载体 | 是否改权重 |
|---|---|---|---|
| 第0层 | 模型自身记忆（身世/风格/真人视角） | 权重内化 | **是**（训练期） |
| 第1层 | 即时情感状态 | 推理期向量注入 | 否 |
| 第2层 | 风格外挂 | peft 适配器 | 否 |
| 第3层 | 知识检索 | 向量库 | 否 |
| 第4层 | 对话历史 | 外挂记忆库 | 否 |

## 三、第 0 层：模型底层直接调整

### 3.1 角色风格预训练（保留）
以角色对话语料做风格预训练，把说话风格（语气、句式、口头禅）写入权重。

### 3.2 灾难性遗忘优化（核心创新）
风格预训练完成后，对模型底层做**针对性遗忘优化**：主动诱导模型遗忘"自己是 AI/助手"的通用身份知识。

灾难性遗忘在此处从"训练事故"转变为**主动工程手段**——通过有选择的遗忘，使模型丧失 AI 自我认知，仅保留角色身世与说话风格，从而**以角色自身的视角存在**。

### 3.3 身世内化（模型自身记忆）
将背景故事、世界观、经历等"对话之前的人生"合并微调进权重。模型在对话前就已"记得"自己的过去，无需每次注入。

## 四、两级记忆体系

| 层级 | 内容 | 载体 | 原因 |
|---|---|---|---|
| **外挂记忆** | 我与用户之间的**对话历史** | 第4层外挂（检索/记忆库） | 对话持续累积，context 上限（1M token）远不足以承载 |
| **模型自身记忆** | 对话之前的**背景/身世/世界观** | 第0层权重内化 | 属于"一生"的固定设定，天然应长在模型内部 |

## 五、提示词层（大砍）

- **保留**：固定短锚点——"你现在是 XX，你在一个真实世界。"
- **移除**：长角色提示词（你是谁/什么性格/什么情感/怎么说话）。此类信息已由第 0 层内化，重复写入冗余且会与底层记忆冲突。

## 六、第 1 层：语义回响（思考链中断注入）

负责**即时情感状态**的表达：

```
① 思考阶段：模型输出 <think>...</think>，思考时尽量使用情感词
   → 捕获情感相关 hidden_state 入池（情感筛选）
② 硬中断：检测到 </think>（token级，如 Qwen3 id=151668）→ 强行中断生成
   → 计算思考阶段全部向量的【总体向量】（此刻的情绪底色）
③ 正文阶段：每个 token 的 logits 叠加 总体向量 @ 投影矩阵 × λ
   → 正文在表示层持续携带该情感："情感先在脑中想好，再表达"
```

关键实现（未修改任何现有源码，独立创新模块）：
- [思考链注入器.py](experiments/思考链注入器.py)：继承 回响注入器 复用钩子/投影/池，重写生成循环
- [思考链中断测试.py](experiments/思考链中断测试.py)：三组同种子对比验证

## 七、通用兼容层（跨模型即插即用）

```
任意模型输入
  → 查因子表（hidden_dim × 架构族 × 量化）
  ├─ 第一步：命中预制参数 → 直接使用实测最优 λ/γ/τ（深度定制化）
  └─ 第二步：未命中/验证不佳 → 思考链中断方案 + 保守 λ（兜底）
  → 全程在线坍缩检测（熵<0.6 或重复率攀升 → 自动降 λ/关回响层）
```

### 7.1 通用注入值公式
```
λ = 基础值(hidden_dim) × 架构族因子 × 量化因子
基础值：扫描表优先（896/1536/2048/3584），公式兜底
架构族因子：Qwen2.5=1.0，Qwen3≤1.7B=0.3，Qwen3≥4B=0.6，
            Gemma=0.7，SmolLM=0.5，Phi=0.8
量化因子：fp16=1.0，4bit=0.75
```

### 7.2 已验证覆盖
| 维度 | 范围 |
|---|---|
| hidden_dim | 896 ~ 3584 全档位（含 1024/2304/2560/3072） |
| 架构族 | Qwen2.5 / Qwen3 / Gemma / Phi / SmolLM |
| 量化 | fp16 + 4bit |
| 坍缩问题 | 25 配置全可控 |

## 八、实验验证数据

### 8.1 多模型对照（19 配置，5 轮/配置）
- Qwen2.5 全系回响有效（熵 +40~45%）
- Qwen3-0.6B/1.7B 在 Qwen2.5 扫描表 λ 下坍缩（重 0.86~0.92）→ 通用注入值修复
- Gemma 命中率最高（0.41），Phi-3.5 中文命中率≈0（语言适配探针）

### 8.2 Qwen3 通用注入重测（6 配置）
- Qwen3-4B：λ=0.059 → 回重 0.06（优秀）
- Qwen3-1.7B 4bit：λ=0.023 → 回重 0.42（恢复可用）

### 8.3 思考链中断方案（三组同种子）
| 模型 | 方案 | λ | 熵 | 重复率 |
|---|---|---|---|---|
| Qwen3-4B | 裸 | — | 0.43 | 0.014 |
| Qwen3-4B | 全面纠正 | 0.059 | 0.68 | 0.009 |
| Qwen3-4B | **思考链纠正** | 0.059 | 0.66 | **0.007** |
| Qwen3-1.7B | 预制·全面纠正 | 0.03 | 0.40 | **0.84（坍缩）** |
| Qwen3-1.7B | **思考链纠正** | 0.03 | 0.69 | **0.0036** |

**关键结论**：思考链中断方案把 Qwen3-1.7B 从坍缩（重 0.84）拉回 重 0.0036——两级策略第二步兜底成立。

## 九、端到端全流程

```
【准备阶段】
  角色材料收集（背景日志/世界观/身世/对话风格）
    → 风格预训练语料 + 身世内化语料
    → 第0层训练：风格预训练 → 灾难性遗忘优化 → 身世内化
    → 得到"底层记忆化"角色模型

【部署阶段】
  固定短锚点提示（你是XX，你在真实世界）
  + 四层推理增强（回响/LoRA/RAG/外挂记忆）

【推理阶段】（第1层语义回响）
  思考链（捕获情感向量）→ </think> 硬中断 → 总体向量定格 → 正文注入
  + 外挂记忆读写（对话历史）
  + 在线坍缩检测兜底

【验证阶段】
  5 项图灵基准复测（EmoCharacter/HeartBench/LLM-Judge/TuringBench/HEART-BENCH）
  判定：5/5 反超裸基座 → 模型达标
```
