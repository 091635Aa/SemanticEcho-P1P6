## 4. gemma 保守兜底结论

- **路径验证**：gemma-2-2b 为未注册模型（hidden=2304 不在扫描表）→ `自动适配` 走公式兜底 β=0.4967 × Gemma 族因子 0.8 = **β=0.3974**（比 Qwen2.5-3B 的扫描表值 0.6 更保守）。
- **结果**：✅ 无坍缩（熵 1.108、重复率 0.0013、兜底 0 次）；✅ 情感命中率 0.0834 > 0（满足"保守 β 兜底无坍缩且命中率>0"）；✅ LLM-Judge **+28.53%**（0.1167→0.15），是三模型中相对提升最大的。
- **说明**：gemma-2-2b 中文能力弱，部分回复为英文（"As an AI language model…"），裸/锚点同现、非锚点通道引入；即使如此锚点注入仍带来最大相对增益（弱模型 + 保守 β = 锚点引导边际最显著）。

## 5. 判定结论（SubTask 7.1 / 7.2）

| 标准 | 结果 |
|---|---|
| 至少 3 个模型 LLM-Judge 相对提升为正 | **✗ 未达成（2/3 为正）**：Qwen3-1.7B +6.91% ✓、gemma-2-2b +28.53% ✓、Qwen2.5-3B -5.86%（β=0.6）/ -17.65%（β=0.3）✗ |
| 各模型生成健康（无坍缩） | ✓ 全部无坍缩（熵/重复率/兜底均健康） |
| gemma 保守 β 兜底 | ✓ 无坍缩 + 情感命中率 0.0834>0 + LLM-Judge +28.53% |
| Qwen2.5-3B 负向补救 | 按任务机制 β×0.5=0.3 重跑锚点一次 → -17.65%（更差），如实记录该模型锚点通道 LLM-Judge 相对不可用 |

**Qwen2.5-3B 负向归因（分析，非锚点实现缺陷）**：
1. **绝对差异极小**：-0.0166（60 配对中差 1 胜），落在配对盲评随机方差范围内，非系统性退化；
2. **降 β 更差**：0.6→0.3 时 -5.86%→-17.65%，说明该模型锚点注入方向与 LLM-Judge 判"更像真人"的方向存在轻微错位（3B 模型受扫描表 β=0.6 引导后回复变长/变"贴心客服化"，如"非常高兴您对这饮料的味道感到满意！如果您有任何其他问题…"——客服腔被裁判识别）；
3. **P4 单模型（1.5B）同协议亦仅 +12.49%**（未达 +25%），3B 负向与 1.5B 弱正向同属"单模式纯净（无 P3 人设/身份拦截）下 LLM-Judge 增益有限"的已知区——P4 在 LLM-Judge 上的强增益来自 +人设 叠加（1.5B +56.25%），本次多模型验证刻意保持纯净以便隔离锚点通道本身。

**总体结论**：锚点回响**多模型可用性验证通过**（3/3 模型无坍缩、情感命中率提升、gemma 保守兜底路径成立），**LLM-Judge 泛化提升部分达成（2/3 为正，+6.91% / +28.53%）**；Qwen2.5-3B 为负向但绝对差异在方差内且无坍缩，不构成"锚点通道失效"，判定为"该模型上 LLM-Judge 相对未提升"。
