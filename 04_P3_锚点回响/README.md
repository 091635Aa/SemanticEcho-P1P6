# 语义回响 · 第四代 锚点回响（Anchor Echo, AE）

> **一句话定位**：锚点回响（P4）＝用模型自身的 token-embedding 权重 `W_e` 作为只读映射接口，把「K 维情感锚点质心」的稠密余弦打分做成低秩 logits 偏置，按会话目标情感权重 `v_target` 极性定向注入——**不写权重、不挂钩子、全词表覆盖、可降级到闭源 API**。

> 版本：v1.0｜日期：2026-08-10｜定位：语义回响家族第四代方案（P1 语义回响 → P2 兼容层 → P3 情感潮汐解码 ETD → P4 锚点回响 AE）

---

## 1. 四代方案空间对照表

| 维度 | P1 语义回响 | P2 通用兼容层 V2 | P3 情感潮汐解码 ETD | **P4 锚点回响 AE** |
|---|---|---|---|---|
| 操作空间 | 表示空间（hidden_state） | 配置空间（λ/γ/τ 自动适配） | 概率空间（logits 乘性重加权） | **嵌入空间（token-embedding 权重）** |
| 情感载体 | 回响池质心（模型内部向量） | —（参数体系，本身不注入） | 外部 VAD + 稀疏情感词表 | **K 维情感锚点质心 E ∈ R^{K×d}（6 维）** |
| 需本地权重 | 是（必须本地模型 + hook） | 注入时依赖 P1/P4 通道 | 否（文本感知即可） | **是（需 `get_input_embeddings()`；有三级降级）** |
| 是否改权重 | 否（hook 只读 hidden_state） | 否 | 否 | **否（只读引用，sum/data_ptr 断言零修改）** |
| 打分密度 | 全词表稠密（随机投影 V 维偏置） | — | 稀疏（情感词表 ≈ 千级 token） | **全词表稠密但低秩（S ∈ R^{V×K}，K=6）** |
| 闭源 API 可用性 | 不可用 | 提示级（思考链兜底） | 部分（logprob/文本感知） | **三级降级链路（embedding→logprobs→提示）** |
| 注入内存成本 | 投影矩阵 hidden×V（1.5B 约 933MB fp32） | — | 词表 dict（≈KB） | **打分表 V×K×2B（1.5B 仅 1.8MB fp16）** |
| 阶段检测 | 思考/正文软切换 + 阶段 λ | — | 目标决策器输出 α | **目标决策器输出 v_target/β（复用潮汐决策器）** |

**P4 与前三代的关系**：纯增量、**正交可叠加**。P1 提供「质心→投影→注入」骨架（P4 把固定随机投影换成模型自身 embedding 产出的低秩打分表）；P2 提供自动适配体系（扫描表扩展为五元组，新增 β/T_anchor/K）；P3 提供「感知/决策/表达」三层模块化结构与退化兜底（目标层完全复用潮汐决策器）。P4 与 P3 人设/潮汐叠加已验证有正向边际增益（LLM-Judge +56.25%）。

## 2. 三层架构（感知 / 目标 / 表达）

```
用户消息 ─→ 潮汐感知器.测量() ─→ 潮汐决策器.计算目标() ─→ V_target / α
     │                                                      │
     │── 思考链注入器（思考链文本，可选）─────────────────────→ 目标决策器: v_target, β
     │── 显式情感指令（可选）─────────────────────────────────→│
     └──────────────────────────────────────────────────────┘
                                                        ↓
    模型前向(logits) ── ① 回响注入器 ── ② 潮汐解码器._情感引导
                     ── ③ 锚点解码器.注入偏置 ── 采样 → 句状态/密度/兜底 → 输出
```

| 层 | 模块 | 职责 |
|---|---|---|
| **感知层** | `潮汐感知器`（复用 P3） | VAD 三维情感测量 + 会话轨迹；`思考链注入器`（可选）提供思考链文本 |
| **目标层** | `目标决策器.py`（新增） | VAD→锚点映射（方向余弦+平方放大）、共情公式、多源融合（潮汐/思考链/指令）、角色感知（0.7·角色+0.3·用户）、自动适配 β；内部复用 P3 潮汐决策器 |
| **表达层** | `锚点库.py`（扩展） | 6 维情感锚点质心 E（每维 50 中文种子词，含网络流行语：破防/泪目/内耗/扎心）；预计算打分表 S ∈ R^{V×K}；只读校验（sum/data_ptr 断言） |
| | `锚点解码器.py`（新增） | 稠密打分注入 + 自回归生成循环 + 在线退化兜底；接口签名对齐 P3 回响注入器 |
| | `混合锚点器.py`（新增） | 锚点 × 回响 × 潮汐 三通道正交叠加，独立开关 |

### 核心公式

```
打分表:   S[w, k] = cos(W_e[w], e_k)，E 每行 L2 归一化          （锚点库）
目标:     v_target = w_潮汐·v_潮汐 + w_思考链·v_思考链 + w_指令·v_指令，L2 归一化（目标决策器）
注入:     logits[w] += β · tanh( S[w]·v_target / T_anchor )    （锚点解码器，tanh 有界防坍缩）
β 自适应: β = β_基 × (1+Δarousal) × min(1, 活跃度×2.5)，封顶 β_上限
自动适配: β = 扫描表或公式 × 架构族因子_锚点 × 量化因子（4bit=0.75）
退化兜底: 重复率>0.6 或 熵<0.6 → β×0.5；连续 3 次 → β=0（锚点通道静默）
```

**只读保证（工程指标）**：全部计算基于 `W_e.detach().float()` 副本，原始权重仅做 `sum`/`data_ptr` 校验；实测 `sum_before=sum_after=-9400.0`、data_ptr 一致，**权重零修改**。

## 3. 混合锚点器：三通道正交叠加

| 通道 | 注入项 | 默认 | 操作空间 | 说明 |
|---|---|---|---|---|
| **A 锚点** | `β·tanh(S@v_target/T_anchor)` | β=0.8, T=0.3 | 嵌入空间低秩稠密 | 核心通道，K=6 打分表 1.8MB |
| **B 回响** | `λ·(池质心@投影矩阵)` | λ=0.08 | 表示空间情感底色 | 复用 P1 回响注入器，GPU 投影 |
| **C 潮汐** | `α·引导倍率·极性词表偏置` | 倍率=6~12 | 概率空间方向密度 | 复用 P3 极性词表逻辑 |

三通道均作用于 **logits 加法**（正交 = 各自空间互不读写、可独立开关）：`logits = base + λ·(质心@投影) + α·倍率·词表偏置 + β·tanh(S@v_target/T)`。在线退化兜底作用于全部通道（连续 3 次 → 全部归零 = 纯裸采样）。实测全开（β=0.8 + λ=0.08 + 倍率=6）**无坍缩**：熵 1.42→1.67（+17%）、回复长度 135→54 字对齐真人、无空回复；本地 7B / DeepSeek pro 双裁判下全开均优于裸（+55.6% / +100% 相对）。

## 4. 三级接口降级链路

| 级别 | 前置条件 | 打分方式 | 注入方式 | 适用对象 |
|---|---|---|---|---|
| **① 本地 embedding 直读**（主路径） | `model.get_input_embeddings()` 可用 | 全词表预计算 S ∈ R^{V×K}（1.8MB fp16） | `logits += β·tanh(S@v_target/T_anchor)` | 全部本地 HF 模型 |
| **② API logprobs 近似** | 接口暴露 top-k logprobs | 候选受限打分（top-100） | 伪 logits 重采样 | OpenAI/DeepSeek 类 API |
| **③ 锚点提示模式**（纯黑盒兜底） | 无 embedding 无 logprobs | 无打分 | 当前维度锚点词注入 prompt（模板：你现在要用「{维度词}」的语气回复我…） | 完全黑盒 API |

**降级判定顺序**：`判定接口()`：`hasattr(model,'get_input_embeddings')` → ①；否则 `logprobs=True` 可请求 → ②；否则 → ③。

**验证结论**（Qwen2.5-1.5B，5 条情感提示，种子 42）：
- **② ≈ ①（无损退化）**：top-100 候选受限注入与本地全词表注入熵差仅 **0.67%**（<10%）、命中率零损失、输出逐字一致——锚点偏置为有界 tanh（±β），只显著抬升与目标方向余弦高的一小簇候选，top-100 已完全覆盖；
- **③ 方向正确（零内部访问）**：生成无异常、无坍缩（熵 1.82），文本级情感命中率 **0.0465 > 裸 0.0349**（+0.0116），代码打点证实 `get_input_embeddings()`/打分表/注入入口 调用数全 0；
- 质量递减符合预期：**① ≈ ② > ③**，三级共享同一目标决策器与锚点库词集。

## 9. 快速使用示例（加载模型 → 构建锚点 → 生成）

```python
# -*- coding: utf-8 -*-
# 依赖：pip install torch transformers cnsenti
# 模型：Qwen2.5-1.5B-Instruct（可换任意支持 get_input_embeddings 的 HF 模型，β 自动适配）
import os, sys, torch
from transformers import AutoModelForCausalLM, AutoTokenizer

锚点回响目录 = os.path.dirname(os.path.abspath(__file__))   # 本 README 所在目录
if 锚点回响目录 not in sys.path:
    sys.path.insert(0, 锚点回响目录)

from 锚点库 import 锚点库
from 目标决策器 import 目标决策器, 自动适配
from 锚点解码器 import 锚点解码器

模型路径 = r"你的模型路径/Qwen2.5-1.5B-Instruct"            # ← 改成你的模型路径
设备 = "cuda" if torch.cuda.is_available() else "cpu"

分词器 = AutoTokenizer.from_pretrained(模型路径, trust_remote_code=True)
模型 = AutoModelForCausalLM.from_pretrained(
    模型路径, torch_dtype=torch.float16 if 设备=="cuda" else torch.float32,
    trust_remote_code=True).to(设备)
模型.eval()

# ① 构建锚点（6 维情感质心 + 预计算打分表，只读，不写权重）
锚点库实例 = 锚点库(模型, 分词器).构建()
只读结果 = 锚点库实例.记录只读基线()          # sum/data_ptr 基线（后续验证零修改）

# ② 目标决策器（VAD→v_target，β 自动适配；cnsenti 缺失时内置简易 VAD 兜底）
决策器 = 目标决策器(锚点库=锚点库实例)        # 内部复用潮汐决策器/感知器，失败自动降级
β建议 = 自动适配(模型, "fp16")["β"]          # Qwen2.5-1.5B → 0.8

# ③ 锚点解码器（稠密打分注入 + 生成循环 + 在线退化兜底）
解码器 = 锚点解码器(模型, 分词器, 锚点库实例, 决策器,
                 β=β建议, T_anchor=0.3, 稀疏阈值=0.0)

用户消息 = "我今天真的好累，感觉什么都做不好。"
提示 = 分词器.apply_chat_template(
    [{"role": "user", "content": 用户消息}],
    tokenize=False, add_generation_prompt=True)
输入 = 分词器(提示, return_tensors="pt").to(设备)

with torch.no_grad():
    生成ids, 统计 = 解码器.生成(
        输入.input_ids, max_new_tokens=64, 用户文本=用户消息,
        eos_token_id=分词器.eos_token_id)

回复 = 分词器.decode(生成ids[0, 输入.input_ids.shape[1]:], skip_special_tokens=True).strip()
print(f"用户：{用户消息}")
print(f"锚点回复：{回复}")
print(f"指标：熵={统计['平均熵']:.3f} 重复率={统计['重复率']} 情感命中率={统计['情感命中率']:.4f} β={统计['β']}")
print(f"只读校验：{锚点库实例.验证只读(只读结果)}")   # sum/data_ptr 断言零修改
```

> 三级降级：`接口="logprobs"`（top-100 候选受限注入，等价于全词表）／`接口="提示"`（纯黑盒，零内部访问）——见 `接口降级.py`。
> 三通道叠加：用 `混合锚点器.py`（`--锚点β 0.8 --回响λ 0.08 --潮汐倍率 6`）。

## 12. 局限与后续

1. **EmoCharacter 天花板**：1.5B 模型第 3/4 轮固有开头模板（"嗯？谢谢？/太好了！"，裸同样存在）与打乱集跨角色雷同 → 一致性二选一识别 0.70 未追平裸 0.90；fidelity 维度无显著退化、无角色情感污染；
2. **纯净模式 AI 腔**：P4 单模式纯净（默认关闭 P3 人设/身份拦截）在 LLM-Judge 上仅 +12.49%，未达 +25% 线——AI 腔抑制是 P3 的强项，P4 锚点与其正交叠加（+人设 +56.25%）方兑现增益；
3. **3B 方差内负向**：Qwen2.5-3B 上 LLM-Judge -5.86%（60 配对差 1 胜），降 β 复测更差，判定为方差内负向、不构成通道失效；
4. **后续方向**：锚点维度扩至 7（新增"流行语"维）、英文锚点词集完善、HEART-BENCH 类低熵基准的稀疏注入优化、与第 0 层权重级方案（底层记忆化）的叠加。
