# P4 锚点回响（Anchor Echo）· Task1 灵感定稿与可行性验证报告

- 日期：2026-08-10
- 模型：Qwen2.5-1.5B-Instruct（fp16，CUDA:0；embedding 权重 shape=(151936, 1536)，tied）
- 环境：Python 3.10.11 / torch 2.5.1+cu121 / transformers 4.57.6 / RTX 3080 16GB
- 方法：以模型自身 token-embedding 权重为只读接口，6 维情感锚点词集（每维 10 个中文种子词），
  维度锚点质心 = 种子词向量均值后 L2 归一化；词向量 = 该词各 token 嵌入均值（中文 BPE 多 token 取均值）。
- 中性词 15 个：桌子 电脑 椅子 马路 天气 数字 蓝色 苹果 时间 材料 规则 声音 纸张 玻璃 金属
- 词库外近义情感词 10 个：扎心 破防 心累 崩溃 泪目 上头 内耗 治愈 宠溺 孤寡（P3 稀疏词库外，稀疏打分全为 0）

---

## 一、验证 a：方向分离度

### 1.1 逐维度：种子情感词 vs 中性词 与对应锚点的余弦相似度（主模式：原始 embedding）

| 维度 | 情感词 均值±std | 中性词 均值±std | 均值差 | t 统计量 |
|------|----------------|----------------|--------|----------|
| 温柔 | 0.4853±0.0939 | 0.1365±0.0482 | +0.3488 | 10.83 |
| 开心 | 0.5985±0.1048 | 0.1031±0.0388 | +0.4954 | 14.31 |
| 难过 | 0.5550±0.1105 | 0.1355±0.0495 | +0.4195 | 11.28 |
| 愤怒 | 0.5189±0.1360 | 0.1146±0.0304 | +0.4043 | 9.25 |
| 害怕 | 0.6154±0.0855 | 0.1186±0.0320 | +0.4968 | 17.58 |
| 平静 | 0.5131±0.1300 | 0.1111±0.0397 | +0.4019 | 9.49 |

6 个维度的种子词相对各自锚点的余弦均值全部 ≥ 0.48，而中性词仅约 0.10~0.14；
均值差 +0.35 ~ +0.50，t 统计量 9.3 ~ 17.6，方向分离度**强显著**。

### 1.2 全词 max 余弦对比（所有情感词 vs 所有中性词，相对全部 6 锚点取最大）

| 组别 | 数量 | max 余弦 均值±std |
|------|------|-------------------|
| 全部情感词（6×10=60） | 60 | 0.5486±0.1165 |
| 全部中性词 | 15 | 0.1495±0.0478 |
| 差值 | - | **+0.3991** |

任意情感词都能在 6 锚点中找到高相似维度（max 约 0.55），而中性词的 max 仅约 0.15，两者分布几乎不重叠。

### 1.3 两种构造模式对比（原始 vs 层归一化）

| 模式 | 平均 t | 平均均值差 | 全情感 max 均值 | 全中性 max 均值 |
|------|--------|------------|----------------|----------------|
| 原始 | **12.12** | +0.4278 | 0.5486 | 0.1495 |
| 层归一化（减均值除 std） | 11.69 | +0.4272 | 0.5475 | 0.1493 |

结论：**层归一化几乎不带来增益（平均 t 反而略低）**，说明 Qwen2.5 原始 embedding 本身已具备清晰的情感方向性。
主模式选定：**原始 embedding**（分离度略高、无额外计算）。

## 二、验证 b：只读证明

构建锚点 + 跑一次逐 token 打分前后，对原始 embedding 权重 W_e 断言：

| 指标 | 构建/打分前 | 构建/打分后 | 一致 |
|------|-------------|-------------|------|
| W_e.sum() | -9400.000000 | -9400.000000 | True |
| W_e.data_ptr | 30690902016 | 30690902016 | True |

结论：**零修改**。全部计算基于 `W_e.detach().float()` 副本，原始权重仅被读取；
不 in-place、不改 requires_grad，不影响后续推理。

## 三、验证 c：近义覆盖对比（P3 稀疏 vs P4 稠密）

### 3.1 词库外近义情感词（P3 稀疏打分 = 是否出现在种子词库，均为 0）

| 词 | P3 稀疏 | P4 稠密（max 余弦） |
|----|---------|---------------------|
| 扎心 | 0 | 0.1970 |
| 破防 | 0 | 0.1263 |
| 心累 | 0 | 0.2356 |
| 崩溃 | 0 | 0.2865 |
| 泪目 | 0 | 0.2504 |
| 上头 | 0 | 0.0365 |
| 内耗 | 0 | 0.0689 |
| 治愈 | 0 | 0.2481 |
| 宠溺 | 0 | 0.2683 |
| 孤寡 | 0 | 0.1896 |
| **平均** | **0（完全无法识别）** | **0.1907** |

对比基线：中性词平均 max 余弦 = 0.1495±0.0478（阈值 = 0.1495+2σ = 0.2451）。

- 平均值 0.1907 高于中性词均值 +27.6%，但**未超过"均值+2σ"阈值（0.2451）**，整体判定为**弱成立/部分成立**。
- 个体层面：10 个近义词中 **7 个（扎心/心累/崩溃/泪目/治愈/宠溺/孤寡，≥0.19）被稠密打分明显识别**；
  3 个网络流行语（上头 0.037、内耗 0.069、破防 0.126）识别弱，是拉低均值的主因。
- 相对 P3 稀疏（10/10 全为 0），P4 稠密对 7/10 词产生了有效识别信号，已证明稠密打分确实"能认出"词库外情感词，只是强度一般。

### 3.2 top-30 高频普通 token 误报检查

对一段约 400 字的中文文本 tokenize 后按频次取 top-30 非停用 token，逐一计算 P4 max 余弦：

- 高频普通 token 平均 max 余弦 = **0.1087**，低于近义词平均 0.1907，**无显著误报**。
- 个别接近情感语义的子词 token（如"的情感" 0.3086、"隐藏" 0.1834、"提取" 0.1717）得分偏高属合理——它们本身携带情感/情绪语义，不构成误报。

## 四、总结论

| 验证项 | 结果 | 判定 |
|--------|------|------|
| a. 方向分离度 | 6 维 t=9.3~17.6，均值差 +0.35~+0.50；全情感 max 0.549 vs 全中性 0.150 | **强成立** |
| b. 只读证明 | sum 与 data_ptr 前后完全一致 | **成立（零修改）** |
| c. 近义覆盖（P3 稀疏 0/10 vs P4 稠密 7/10 可识别） | 平均 0.1907，未过 2σ 阈值；无误报 | **部分成立，需增强** |

**总判定：锚点方向性成立。** P4 的核心前提——"模型 embedding 空间中，情感锚点质心具备清晰、可分离的方向"——已被验证 a 强有力地证实（这是本 Task 的基石）。只读约束同时得到证明。近义覆盖部分成立，说明稠密打分机制有效但强度有限，需要备选方案增强后再进入后续 Task。

### 备选/增强方案（按优先级）
1. **更大词集 / 多词锚点**：将网络流行语（上头、内耗、破防、泪目、治愈、宠溺等）直接纳入种子词集，每维扩至 30~50 词，提高质心稳定性与词库外覆盖。
2. **token 级聚合方式**：词得分由"token 向量均值"改为"逐 token 打分后 max-pooling"（取最响应的 token），可避免均值稀释弱语义词。
3. **锚点扩维**：在 6 维基础上增加"流行语情感"混合维，或在打分时对 logits 使用温度缩放后再注入（衔接后续 Task 2 的引导强度实验）。
4. **层归一化增强：经实测无效**（平均 t 12.12 → 11.69），不作为增强方向；原始 embedding 已够用。
