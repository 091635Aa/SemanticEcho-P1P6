## 4. 关键结论

### 4.1 是否无坍缩 —— 是（各档重复率不升反降）
- 三档 β 重复率均低于裸模式（裸 0.1302 → 锚点 0.076~0.092，降幅 4~5pp）。
- 裸模式重复率偏高主要来自"天气"提示词的模板化重复（0.3059）；锚点注入的 tanh 有界偏置 + 在线退化兜底 + 句内密度控制有效抑制了重复。
- 四模式均 0 次触发在线兜底，强档 β=1.2 也未出现重复崩溃。

### 4.2 熵是否退化 —— 是（未达 95% 硬阈值，属方向性引导的机制性收窄）
- 三档熵为裸的 88.6% / 93.5% / 86.3%，均低于任务设定的 95% 阈值。
- 机制解释：`β·tanh(S@v_target/T_anchor)` 将分布向目标情感方向收窄，熵下降是方向性引导的固有代价；β=0.8 默认档下降最温和（-6.5%），仍在"轻微收窄"范围，但按硬性判定标准记为不通过。
- 三档熵非单调（0.8 档 2.105 > 0.4 档 1.994），与单条单次采样的随机性及生成路径漂移有关。

### 4.3 情感命中率提升幅度 —— 三档均提升，+0.3 ~ +3.9 个百分点
- β=0.4：+2.4pp；β=0.8：+0.3pp；β=1.2：+3.9pp（提升最显著）。
- 提升幅度整体偏小：命中率统计基于单 token 情感词集，而注入也会推高与目标方向相似的非词集普通词（不进入命中计数），稀释了词集词的相对增益。

### 4.4 β 敏感性 —— 非单调，0.4 与 0.8 区间不敏感，1.2 档出现"过注入边界"迹象
- 命中率随 β：0.4→0.8 不升反降（0.1266→0.1054），0.8→1.2 显著上升（→0.1414），**非单调**，判定不通过。
- 原因分析：① 每条仅生成 1 次的采样噪声不可忽略（β=0.8 档在提示词 1/2 上命中率低于 β=0.4 同提示词）；② β 增大使 tanh 饱和面扩大，与目标方向一致的非词集普通词被同步推高，对严格词集命中率形成挤压。
- **过注入边界记录**：β=1.2 档熵退化最明显（熵比裸 0.863 < 0.95），分布收窄过度；虽未出现重复崩溃（重复率 0.082，兜底 0 次），但已呈现"过注入"的早期迹象（多样性过度受损），记为**过注入边界（轻度）**。建议生产档位以 β=0.8 为主，β=1.2 仅作短回复场景使用。

### 4.5 额外延迟 —— 达标（≈0，实际略快 0.7%）
- 锚点模式单条耗时 9.86s vs 裸 9.94s，增幅 -0.7%（打表矩阵乘 `S@v_target` 为 GPU 微秒级开销，低于时序噪声），远小于 5% 门槛。

### 4.6 显存 —— 无额外负担
- 四模式峰值 3864~3866MB（模型 fp16 权重为主），锚点打分表仅 1.8MB（fp16），各档之间无显存累积（每条前已 empty_cache）。

## 6. 总结论

- **判定：✗ 不通过**（整体），其中 **无坍缩 / 情感命中率提升 / 额外延迟 3 项通过**，**熵不退化 / β 敏感性 2 项不通过**。
- 锚点回响在 Qwen2.5-1.5B 上：**不坍缩、无额外延迟、命中率有提升**（+0.3~3.9pp）；代价是**分布熵收窄 6.5%（默认档）~13.7%（强档）**，未达到"熵 ≥ 裸 95%"的严格阈值；**β 敏感性非单调**（0.4/0.8 区间不敏感，1.2 档命中率跃升但熵显著退化，属过注入边界早期迹象）。
- 建议：后续（多模型/多轮对照或调参）可关注 ① β=0.8 与 0.4 之间命中率非单调是否由单次采样噪声主导（可加 3~5 次重复取均值复核）；② 通过降低 `T_anchor` 或引入"仅对词集 token 定向、其余 token 零偏置"的稀疏注入，在保命中率的同时减少熵收窄。
