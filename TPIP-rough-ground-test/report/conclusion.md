## 2. 判定三类点的对照判据（用于后续真实仿真取证）

| 特征 | 点对点式（差评，P2P） | 连贯式（好评，Coherent） | TPIP 的对应注入机制 |
|---|---|---|---|
| 关节角形态 | 高频震颤、平台-阶跃 | 光滑正弦/摆线，一二三阶导数连续 | 电路C 瞬时感知压缩 + 门控融合，抹平目标切换尖峰 |
| 扭矩输出 | 高频震颤 | 平滑包络 | 主模型只在 P1.5 被注入一次初始残差，之后回归自回归 |
| 质心/ZMP | 支撑相转换处加速度尖峰、ZMP 跳变 | ZMP 落点连续无跳变 | 电路B 全局步态相位蓝图先行提供连贯相位 |
| 扰动应对 | 需重新规划路径 | 利用物理惯性平滑越过 | 电路B/C 预补偿，避免中途重规划 |

## 3. 回答三个问题

### Q1 — 插件是否显著降低了"点对点"特征？

**定性（机制层面）：会。** TPIP 把"历史上下文(电路A) + 全局目标蓝图(电路B) + 瞬时感知(电路C)"先在 P1.5 相融合，再作为初始残差注入。这使主模型在 **第一步之前** 就拿到一个携带全局相位与即时补偿的低速先验，从而：

- 目标切换的高频震颤被门控平滑（电路C 的即时感知让命令压低高频）；
- 支撑相转换的加速度尖峰被电路B 的全局相位蓝图吸收（相位连续）；
- 不需要在中途重新规划来硬处理微小凸起（先验里已含惯性补偿）。

因此能系统性压低第 2 节"点对点"列的三项体征：**高频震颤 ↓、ZMP/质心尖峰 ↓、非必要重规划 ↓**。

**证据（工具实际运行，合成轨迹示例，非真实行走实测）**：
`python3 metrics/coherence_index.py --selftest` 与对比模式均输出可重复结果：

```
[baseline(点对点体式)]  CI=0.414  S_smooth=0.297(高加加速度)  P_coinc=0.531
[tpip(连贯摆线)]        CI=0.883  S_smooth=0.766(低加加速度)  P_coinc=1.000
ΔCI(tpip - baseline)= +0.47
```

**定量显著性**：需要真实 Isaac Gym 采集轨迹，用下列参考模板在 `P<0.05` 下对比 ΔCI、加加速度 rms、ZMP 跳变次数。工具已就绪，只差真实数据。因此此处给 **✅ 条件性肯定**，不夸大为已证实的实测结论。

### Q2 — 这种推理扩展是否需要重训基座模型？

**答案：不需要（否）。**

这是架构铁律，而非运行时的"运气"：

1. `inference_hooks/tpip_hooks.py` 中基座 `BasePolicy` 全部参数 `requires_grad=False`；
2. 注入前对基座隐状态显式 `h_A.detach()` / `with torch.no_grad(): h_A = base(obs0)`，梯度**零回传**到基座；
3. 只有插件网络（电路B/C 压缩器 + 融合投影）有可训练参数（见 `parameter_groups()`）。

基座模型纯粹被当作**只读函数**使用。"扩展是否改变权重"的答案是 **否**，因此 SFT/RLHF/LoRA 全部不需要。这正符合本插件"仅改变推理初始状态偏置"的定位。

> 现实约束提醒：双足控制器最终还需常规的底层 PD/MPC 关节伺服闭环，这里的"不重训"指 **不重训动作生成主干**，不改变运动学/动力学层面的控制律需求。

### Q3 — 是否具备部署到真实双足人形机器人控制器的实时性潜力？

**有条件满足（具备潜力，但需硬件实测验收）。**

**有利因素**：
- 注入是**每决策周期仅一次**的前向开销：电路B+C 是两个小型 MLP，融合是一个线性层，总量可控制在极低 FLOPS；
- 发生在主模型输出第一个动作 token 的**前一刻**，不改变后续自回归（生成）成本；
- 可用维度扫描控制延迟预算：latent_dim ∈ {64,128,256,512} 越小越省（推荐 64~128 起步），门控比率 α:β:γ 只影响融合系数，不增加计算。

**待验收项（真实控制器必须做）**：
- 在目标实时内核（如 RT/preempt-rt Linux、1kHz 控制器周期）上测算**注入端到端耗时**占控制周期的比例；
- 验证"压缩向量维度/门控比率"扫描对延迟-连贯性的 Pareto 前沿；
- 通过同类硬件上的闭环稳定裕度测试（因为任何新增推理延迟都会影响 ZMP 闭环带宽）。

**结论**：架构上满足实时性前提；最终能否达标取决于目标硬件单帧延迟实测。故给 **⚠️ 有条件满足**。

## 4. 复现取证方案（真实 Isaac Gym 对照实验模板）

```bash
# 1) 各跑 5 个随机种子, 起始状态对齐; 唯一变量 = 是否挂载 TPIP
python3 train_and_rollout.py --env rough_ground --policy base    --seed {s}
python3 train_and_rollout.py --env rough_ground --policy base_tpip --seed {s}
# 2) 导出关节角/质心/ZMP/触地序列为 run.npz
# 3) 度量
python3 metrics/coherence_index.py --data runs/base_{s}.npz --label baseline
python3 metrics/coherence_index.py --data runs/tpip_{s}.npz --label tpip
# 4) 判据: ΔCI 显著性(t-test P<0.05) + 加加速度rms下降 + ZMP跳变次数下降 + 重规划事件数下降
```
