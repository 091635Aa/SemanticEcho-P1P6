# P1~P6 → 足式机器人平移实测 · 最终汇总结论

> 日期：2026-08-26 ｜ 环境：CPU 微仿真（numpy, 无 GPU/Isaac Gym）
> 基座模型族：p2p(点对点僵硬) / standard(标准RL) / transformer(类Transformer)
> 地形：flat(平地) / rough(3cm凸起) / very_rough(10cm碎石)
> 指标：连贯性指数 CI = 0.5×S_smooth(jerk平滑度) + 0.5×P_coinc(步态相图重合度)

---

## 一、做了什么

1. **梳理 P1~P6 机制**：读完全部参考仓库（SemanticEcho / ETD / AnchorEcho / KVResonance / EDD），明确各方案操作空间与核心公式。
2. **建立平移映射表**：把 LLM 的 logits/hidden_state/KV/attention 操作面映射到机器人动作流的"推理期校正项" `a_eff = a_base + Δ_p`（见 [mapping.md](../legged/mapping.md)）。
3. **搭建 CPU 微仿真**：6 关节双足、共享全局步态相位蓝图、自回归动力学、3 种基座模型族。
4. **实现 P1~P6 全部 6 个插件 + 融合方案**：均为零权重只读注入（见 [plugins.py](../legged/plugins.py)）。
5. **三阶段实测**：
   - 阶段A：默认强度全矩阵（3基座×6方案×3地形=54组CI）
   - 阶段B：强度扫描（s=0→1），找每方案最优强度
   - 阶段C：通用架构验证（用p2p上最优s直套其他基座）

## 三、四问回答

### Q1：对足类型机器人的优化有多少？优化率有多少？

**仅在"点对点僵硬基座"上有可观优化：**

| 方案 | 对P2P基座最高优化率 | 对平滑基座(standard/transformer) |
|---|---|---|
| P1 语义回响 | **+7.4%（相对增幅+32.8%）** | ±0%（中性） |
| P3 锚点回响 | +0.7%（微弱正向） | -40%~-48%（**有害**） |
| P6 情感导演 | +0.2%（极微弱） | -38%~-49%（**有害**） |
| P2.5/P4/P5 | 0%（最优=关闭） | -77%~-89%（**严重有害**） |

**结论**：直接平移 LLM 的 P1~P6 到足式机器人，**总体优化率极低甚至有害**。唯一有意义的方案是 **P1 语义回响（惯性回响池）**，在僵硬基座上 CI 从 0.183→0.243（+32.8%），但对已平滑的基座无增益。

### Q2：是否挑模型？

**是的，严重挑模型。**

- **P1 语义回响**：只对"高频震颤/阶跃式"的 P2P 基座有效（+32.8%），对平滑基座中性（±0%）；
- **P3 锚点回响 / P6 情感导演**：对 P2P 微弱正向（<1%），对平滑基座严重负向（-38%~-49%）；
- **P2.5/P4/P5**：对全部基座均为负向或零，最优策略是关闭（s=0）。

**根因**：LLM 的注入方法假设"基座默认输出在特定方向上偏了"（如 AI 腔），注入是"往正确方向推"。但机器人控制中：
- P2P 基座确实"偏了"（高频震颤），所以 P1 的惯性平滑有效；
- standard/transformer 基座**已经学会了自己的平滑动力学**，外部注入一个正弦蓝图反而**破坏了已学到的连贯性**。

### Q3：能否变为通用优化架构？

**直接平移形式下：否（0/6 通过通用性测试）。**

用 P2P 上找到的最优强度直套到 standard/transformer，**没有任何一个方案在三种基座上一致正向**。

### Q4：什么条件下可能通用化？

测试暴露了一个关键设计缺口：**注入方向不能是"推向外部蓝图"，而应是"推向基座自身的平滑流形"**。如果要做通用化，需要：

1. **自适应注入方向**：不注入固定正弦蓝图，而是提取基座自身最近 N 步的"惯性主方向"注入——这对 P2P（平滑掉震颤）和 standard（增强已有惯性）都应是正向；
2. **兼容层(P1.5)做前置门槛**：先测基座的 jerk/相位熵，只有"基座本身足够僵硬"时才开注入，平滑基座自动归零；
3. **乘性而非加性**：P2.5 潮汐的乘性重加权在 LLM 中有界安全，但机器人动作空间维度低、量纲不同，乘性会放大高频分量——需改为"乘性 + 截止频率约束"。

这三个改进**在本测试中尚未实现**，属于后续工作方向。

---

## 四、诚实声明

- 本测试为 **CPU 微仿真**，基座策略为合成模型（线性映射 + 族特征噪声），非真实 RL 策略权重；
- 连贯性指数 CI 是合成指标（jerk 平滑度 + 相图重合度），与真实 ZMP 稳定性不等价；
- 结论的**方向性**（挑模型、P1 唯一有效、融合方案有害）在仿真精度提升后大概率保持，但**具体数值**（+32.8% 等）需在 Isaac Gym + 真实策略上复核；
- 本测试的价值在于：**用可复现的方式暴露了"LLM→机器人直接平移"的根本困难**，而非给出最终部署参数。
