# P1-P6 → 足式/服务机器人控制 平移映射表（Mapping）

> 目标：把「大语言模型 P1~P6 零权重推理期增强」家族，逐一平移到**足式物料/服务机器人**的动作生成主干上。
> 约束：**不重训/不修改基座策略权重**，仅在推理期向动作流注入紧凑向量/偏置。
> 统一作用面（TPIP 同款）：机器人的动作生成器与 LLM 一样是"自回归"的——每步从分布里"抽"一个动作/关节增量。
> 因此 P1~P6 的注入点可由 LLM 的 logits/hidden-state/attention/KV 一一映射到机器人控制信号。

## 平移后统一作用面（TPIP-兼容注入协议）

每个 P 方案被实现为一个**推理期校正项**：

```
a_eff(t) = a_base(t) + Δ_p(t, φ, q, dq, history, terrain)
```

- `a_base` = 基座策略（冻结，只读），默认产"点对点"式僵硬动作（阶跃/重规划/PWM 震颤）；
- `Δ_p` = 第 p 号插件的推理期注入（紧凑维度，CPU 可算）；
- `φ` = 多关节**共享全局相位**（电路B 蓝图），是所有足式方案共用的节拍器。

三问被翻译为：
1. 是否显著压降"点对点"体征（jerk、相位离散、重规划）→ 由连贯性指数 CI 测；
2. 是否需重训基座 → **全插件为零权重只读注入**；
3. 是否挑模型/能否成通用架构 → 同一插件配置在不同基座"模型族"上是否一致正向。
