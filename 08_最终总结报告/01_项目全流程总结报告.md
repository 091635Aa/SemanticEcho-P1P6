## 一、项目背景与总体技术路线

### 1.1 核心问题

大模型情感表达的两大矛盾：
1. **"AI 味"**：即使是旗舰大模型，输出也常带"作为/助手/模型/如果有什么问题请随时找我"等机械腔，图灵测试一测就穿帮。
2. **参数规模 vs 情感能力**：情感表达能力与参数量的关系并非线性——1.5B 小模型的情感潜力远未被开发，瓶颈在"表达层"而非"理解层"。

### 1.2 四套架构路线（本项目独立提出的四大方向）

| 架构 | 操作空间 | 核心机制 | 是否需要本地权重 |
|---|---|---|---|
| **五层架构**（第0层+第1层语义回响） | 表示空间 + 权重空间 | 训练期底层改造 + hidden_state 钩子 → 回响池质心 → logits 注入 | ✅ |
| **通用兼容层 V2** | 配置空间 | 因子表/公式归一化 λ、γ、τ，跨模型自动调参 | ✅ |
| **情感潮汐解码 ETD** | **概率空间** | 采样分布乘性重加权 + 情感词预算（外部 VAD 情感认知） | ❌（闭源 API 也能用） |
| **锚点回响 AE** | **嵌入空间** | 模型自身 embedding 只读接口 → 6 维情感锚点稠密余弦打分 → 极性 tanh 注入 | 可选（API 也可用） |

四套架构**正交且可叠加**，本报告覆盖全部四套的研发与实验全过程。

## 二、架构一：语义回响（五层架构，含第 0 层底层改造）

### 2.1 五层架构总览

```
第0层  模型底层（训练期权重级改造）      ← 颠覆核心：让模型"忘记自己是AI"
第1层  语义回响（思考链中断 + 总体向量注入） ← 即时情感状态
第2层  LoRA（风格外挂，可选）
第3层  RAG（知识检索）
第4层  外挂记忆（对话历史）
```

### 2.2 第 0 层：模型底层直接调整（核心创新）

- **角色风格预训练**：用角色对话语料把说话风格写入权重。
- **灾难性遗忘优化**：把"主动遗忘 AI 身份知识"作为工程手段——模型从底层就是角色，而非扮演角色。
- **身世内化**：背景/世界观合并微调进权重，对话前就已"记得"自己的过去。

### 2.3 第 1 层：语义回响（思考链中断注入）

```
① 思考阶段：模型输出 <think>...</think>，思考时尽量使用情感词
   → 捕获情感相关 hidden_state 入池（情感筛选）
② 硬中断：检测到 </think>（token级，如 Qwen3 id=151668）→ 强行中断生成
   → 计算思考阶段全部向量的【总体向量】（此刻的情绪底色）
③ 正文阶段：每个 token 的 logits 叠加 总体向量 @ 投影矩阵 × λ
   → "情感先在脑中想好，再表达"
```

### 2.4 通用兼容层 V2（跨模型即插即用）

- 公式：`λ = 基础值(hidden_dim) × 架构族因子 × 量化因子`
- 已覆盖：hidden_dim 896~3584 全档位 × Qwen2.5/Qwen3/Gemma/Phi/SmolLM 架构族 × fp16/4bit 量化 = **25 配置全可控**。

## 三、架构三：情感潮汐解码（ETD）—— 第三套独立方案

### 3.1 总体架构（三层）

```
① 感知层  潮汐感知器.py   文本 → VAD(愉悦/唤醒/支配)三维情感状态 + 会话轨迹
② 决策层  潮汐决策器.py   共情目标 + 角色VAD基调 + 自适应α + 词汇密度预算
③ 表达层  潮汐解码器.py   p'(w) = p(w)^(1-α) · q_emo(w)^α 乘性重加权 + 极性定向 + 在线兜底
④ 混合    混合注入器.py    回响(表示空间情感底色) + 潮汐(概率空间方向密度控制)
```

### 3.2 核心公式

```
s_emo(w) = 情感词库极性得分（+1 正面 / -1 负面）
k = α × 引导倍率                    # v2.1：k∈[1.0,2.5] 有效区间
logits[方向一致情感词] += k          # 目标 valence 方向抬升
logits[方向相反情感词] -= 0.3k       # 抑制相反极性
logits[AI腔词]      -= 强度×权重     # v4 三通道 AI 腔抑制
```

### 3.3 为什么用乘性重加权而非 logits 加法

- logits 加法把偏置强加给每个候选，小模型上易碾压原分布 → 坍缩；
- 乘性重加权是**有界插值**（α∈[0,1]），数学上不可能坍缩，只会把概率质量向情感词倾斜。

## 四、架构四：锚点回响（AE）—— 第四套独立方案

> 时间：2026-08-10 ｜ 数据源：P4_锚点回响 全部实验报告（灵感验证/单模型对照/参数扫描/五基准/多模型/三正交/接口降级，详见《历史资料归档\P4锚点回响资料\》）

### 4.1 机制：嵌入空间的"情感-语义地图"

前三代各自的边界：P1 卡在表示空间（**依赖 forward hook，闭源 API 不可用，投影矩阵 933MB 且方向不可解释**）；P2 是调参调度器（本身不注入）；P3 卡在概率空间（**词库稀疏**——只认识词库里的情感词，破防/泪目/内耗/扎心等网络流行语得分为零）。P4 的关键观察：

> `get_input_embeddings()` 暴露的 token-embedding 权重 W_e 是一张天然的、稠密的、可解释的情感语义地图——词表中每个 token 都与"温柔/开心/难过/愤怒/害怕/平静"六维存在确定的余弦关系。既然模型自己"知道"每个词的情感语义，为何不把这张地图直接用作注入接口？

**机制五件套**：

1. **锚点库**：6 个情感维度 × 每维 50 个种子词（含网络流行语：破防/泪目/内耗/扎心/心累/宠溺），逐词取 token 嵌入均值 → 维度质心 → L2 归一化得 E ∈ R^{K×d}（K=6）。**一次性预计算稠密余弦打分表 S ∈ R^{V×K}**（Qwen2.5-1.5B：151,936×6 ≈ 3.6MB fp32 / 1.8MB fp16），对比 P1 投影矩阵 933MB 下降约 3 个量级；全部计算基于 `W_e.detach().float()` 只读副本，原始权重以 `sum`/`data_ptr` 断言校验（实测 sum_before=sum_after=-9400.0、指针一致，**零修改**）。
2. **目标决策器**：复用 P3 潮汐感知器/决策器（cnsenti VAD + 会话轨迹）→ VAD→锚点空间映射（方向余弦 + 平方放大锐化高匹配维）→ 多源融合（潮汐 0.5 / 思考链 0.3 / 指令 0.2，L2 归一化）→ 15 角色基调表角色感知（0.7×角色 + 0.3×用户）→ 强度自适应 β。自动适配沿用 P2 体系：扫描表扩展**五元组** (λ,γ,τ,β,T_anchor)——896→(1.0,0.4)、1536→(0.8,0.3)、2048→(0.6,0.3)、3584→(0.5,0.2)；Qwen3≤1.7B 族因子 0.4 / Gemma 0.8 / 4bit 0.75；未注册模型一律保守 β=0.5 起步。
3. **锚点解码器**：每步解码对 logits 做**极性定向有界注入**（公式见 4.2）+ 在线退化兜底（每 40 token 语义熵<0.6 或 2-gram 重复率>0.6 → β×0.5，连续 3 次 → β=0）+ 句内密度控制（防情感词堆砌）。**零 hook 开销**（一次查表 + 向量乘）。
4. **混合锚点器（三通道）**：锚点(β=0.8) × 回响(λ=0.08) × 潮汐(倍率=6) 正交叠加，全开无坍缩（详见 4.3-⑤）。
5. **接口降级（三级）**：① 本地 embedding 直读（主路径）→ ② API logprobs 近似（top-100 候选受限打分，与本地逐字一致）→ ③ 纯黑盒锚点提示模式（零内部访问，维度级锚点词注入 prompt）。判定顺序 `判定接口()`：embedding → logprobs → 提示。

### 4.2 核心公式

```
S[w,k] = cos(W_e[w], e_k) = (W_e[w]·e_k) / (‖W_e[w]‖·‖e_k‖)      # 全词表稠密余弦打分表 S ∈ R^{V×K}
a(w)   = S[w] · v_target = Σ_k f_k(w)·v_target,k                  # 极性内积（正=朝目标情感方向）
logits[w] += β · tanh(a(w) / T_anchor)                            # 极性定向 tanh 注入（有界）
```

**tanh 有界化的三个理由**：① 每个 token 的 logits 偏移有硬上限 |b|≤β，β 直接等于"最大注入幅度"，机制上杜绝过注入坍缩；② a/T_anchor 量级可控（|f_k|≤1、‖v_target‖₂=1），T_anchor∈(0.1,0.5) 放大弱信号、饱和强信号，与 P1 的 λ 语义解耦；③ 弱信号区 tanh(x)≈x 保持线性可调，与 P3 乘性重加权"有界插值"精神一致。非情感 token 余弦自然稀疏、情感方向 token 被抬升。

### 4.3 关键实验（批次 0-6，全部实测，详见"五、演进历程"P4 批次表）

1. **灵感验证（批次0）**：方向分离度强成立——6 维 t=9.3~17.6、均值差 +0.35~+0.50（原始 embedding 平均 t=**12.12**，层归一化反而略低 11.69 故弃用）；**只读证明**：构建/打分前后 W_e.sum 与 data_ptr 完全一致（-9400.0）；近义覆盖 P3 稀疏 0/10 vs P4 稠密 **7/10**（扎心/心累/崩溃/泪目/治愈/宠溺/孤寡被稠密打分识别，平均 0.1907）。
2. **单模型对照（批次1）**：无坍缩（重复率 0.1302→0.076~0.092 不升反降）、命中率三档全提升、延迟 -0.7%（≈0）；熵收窄问题定位为**负偏置压制** → 稀疏阈值=0.0 修复。
3. **参数扫描（批次2）**：最优 **(β=0.8, 稀疏阈值=0.0, T_anchor=0.3, K=6)**；熵 2.0291 = 裸的 **109.9%**、重复率 0.0787（裸 0.1336）、命中率 0.1279（裸 0.0979，**+3.0pp**）；过注入边界位于 β∈(2.0, 2.5]，生产档位建议 ≤1.6。
4. **五基准（批次3）**：HeartBench **+21.7%**、TuringBench human_likeness **+200%**、LLM-Judge +人设 **+56.25%**、HEART-BENCH 持平（边缘）、EmoCharacter 受天花板限制（详见 6.2 表）。
5. **多模型（批次4）**：Qwen3-1.7B **+6.91%**、gemma-2-2b **+28.53%**（未注册公式兜底 β=0.3974 为最大增益档）、Qwen2.5-3B -5.86%（60 配对差 1 胜，方差内）；**3/3 无坍缩**、情感命中率全部 ≥ 裸。
6. **三正交+双裁判（批次5）**：全开（锚点×回响×潮汐）本地 7B 相对裸 **+55.6%**、deepseek-v4-pro **+100%**，云/本地方向一致（flash 过严无区分度）；熵 1.42→1.67（**+17%**）、长度 135→54 字对齐真人，无坍缩。
7. **接口降级（批次6）**：logprobs top-100 与本地熵差仅 **0.67%**、输出**逐字一致**（tanh 有界偏置只抬升一小簇高余弦候选，top-100 已全覆盖）；提示模式零内部访问（get_input_embeddings/打分表/注入入口三计数全 0），文本级命中率 0.0465 > 裸 0.0349（+0.0116）。

1. **人设系统提示（--人设）**：注入"真人聊天风格"system prompt（口语化、短句、不自我介绍、不客服话术、不讲大道理）→ 直击服务腔/大道理两大低分主因（**最大增益 +0.13~0.17**）。

**裁判加载工程修复（重要）**：16GB 内存机可用 4~8GB 时，`from_pretrained` 加载 7B 裁判在 torch_cpu.dll 固定偏移原生崩溃（0xC0000005，提交内存不足）。**手动加载**：meta 建模 → to_empty(cuda) → 逐分片 safetensors load_state_dict（CPU 峰值仅单分片）。关键坑：`to_empty` 只迁移结构，`__init__` 计算的非持久化 buffer（Qwen2 旋转编码 inv_freq/original_inv_freq）变全零 → 必须按 rope_theta 重算，否则 logits 乱码。权重逐值核对 + 推理验证通过。

### 6.1 五项图灵测试基准（与"裸/四层"同协议）

| 基准 | 测什么 | 判定方式 |
|---|---|---|
| TuringBench | 中文体系图灵检测 | 人似度 = 1 − 被判为 AI 的比例 |

| HEART-BENCH | 记忆驱动人格推理 | (accuracy + empathy + consistency)/3 |

## 九、成果总结与局限性

### 成果
1. 四套正交架构（五层/兼容层/ETD/AE），覆盖"表示空间-配置空间-概率空间-嵌入空间"四大技术路线；
2. 1.5B 小模型 5 项图灵测试 4 项反超裸模型、LLM-Judge 盲评胜率 +91%~+180%（P1/P3），P4 在 HeartBench（+21.7%）/TuringBench（+200%）上大幅反超裸模型并优于 P3 同基准；
3. **P4 补上 P3 词库稀疏短板**（稠密余弦覆盖词库外近义词 7/10），并新增**闭源 API 三级降级兼容**（logprobs 与本地逐字一致、纯黑盒提示可用）——四代正交可叠加（锚点×回响×潮汐三通道全开已验证）；
4. 全部优化步骤正向增益、可复现（同种子同提示）、工程完整（评测/消融/横向齐全）。

### 局限性（诚实说明）
1. LLM-Judge 盲评上 1.5B 仍未稳定反超 Qwen3——**基模表达自然度/内容深度是硬瓶颈**；
2. 解码期引导只能缩小差距、无法抹平；要全绿需"回响架构专属定制模型"（第 0 层训练期改造）；
3. 样本集校准实验（v3 口语化）为负向，说明测试集风格敏感，需谨慎设计评测协议；
4. **P4 专属局限**：① 纯净单模式 LLM-Judge 增益有限（+12.5%，需叠加 P3 人设才达 +56.25%）；② EmoCharacter 受 1.5B 模板天花板限制（裸识别率 0.90 已饱和，fidelity 不退化）；③ Qwen2.5-3B 上 LLM-Judge -5.86% 为方差内负向（60 配对差 1 胜），提示"非所有模型在单模式下都获益"。

### 结论：四代家族

P1（表示空间）证明"情感向量注入"有效、P2（配置空间）让注入强度全模型自动适配、P3（概率空间）摆脱内部依赖（外部 VAD + 词表重加权）、P4（嵌入空间）把"质心投影"迁移到模型自身静态 embedding 只读接口——**用模型自己的词表坐标锚定情感方向，补上 P3 词库稀疏的短板，并把可用范围扩展到闭源 API**。四代正交可叠加，共同构成"从表示到概率到嵌入"的情感表达工程完整拼图。
