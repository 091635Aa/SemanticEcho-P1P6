## 四、各授权等级说服理由

### 普通授权（大厂年费 500 万+/年，优惠后 480 万）
1. **游戏内情感直接变现**：帕姆帮帮已跑通"情绪互动"入口，情感增强让角色对话情感浓度翻倍→ 沉浸感 → 付费（米哈游 ARPU 行业第一，增量付费足以覆盖授权费）。
2. **千万级并发的成本解**：引擎 1.5B 基座 + 显存增量≈0，百万 token 成本约 ¥2-12，在帕姆帮帮的千万级并发下依然便宜。
3. **角色一致性卖点**：OOC/记忆断档是陪伴赛道最大流失原因，引擎提升角色一致性=直接提升玩家留存。
4. **独占 IP 赋能**：授权期内米哈游角色情感表达独占，原神/星铁/绝区零全线受益。
5. **先试后买**：可先在星铁帕姆帮帮场景 PoC（1-2 个角色）验证效果再付款。
6. **窗口期**：新作（Varsapura 等 7/8 款 AI 游戏）2026-2027 密集上线，现在配引擎正好赶产品化。

### 长期授权（独家 8年/10年）
1. **IP 级资产**：米哈游卖的是"角色"，角色会共情=IP 更值钱；8-10 年独家让全线角色情感表达标准统一且独占。
2. **多产品摊薄**：原神/星铁/绝区零/新作+云游戏多端复用，5000 万/8 年摊到每款产品极小。
3. **竞品封锁**：网易/腾讯游戏/库洛/叠纸拿不到同一引擎，二次元情感表达标准由米哈游定义。
4. **下一个战场**：语音陪伴/角色通话是增长点（星野/Talkie 已验证语音付费），长期独家提前卡位。
5. **AI 游戏转型底座**：蔡浩宇"Agent 是虚拟世界唯一标准"，情感增强是 Agent 角色的情感内核，长期布局。
6. **作者陪跑**：8-10 年全程技术陪跑，随新作/新角色迭代调优，深度定制 IP 情感。

### 永久授权（买断/非独占）
1. **一次性买断 IP 情感引擎**：纳入米哈游技术底座，全线产品永久受益，内部化二次开发自由。
2. **资产化+云游戏分发**：买断后可随云·星铁/云·原神分发，跨端体验统一。
3. **彻底封锁**：永久买断后腾讯/网易/库洛永不可得，二次元情感 AI 壁垒最高。
4. **完整交割**：含源码/因子表/评测体系，米哈游可独立维护、接入自研 Glossa 大模型管线。
5. **叙事价值**："米哈游角色=最会共情的二次元 AI"品牌故事，与 1000 亿 AI 投入叙事呼应。
6. **对等心仪条款**：作者心愿单硬件+限定手办写入合同，双方各取所需。

## 五、场景应对（米哈游可能的质疑 → 我们的反驳）

| 对方的说法 | 我们的应对 |
|---|---|
| "我们自研 Glossa，不用外部" | Glossa 是内容生成（配音/美术/代码），帕姆帮帮是游戏内助手——情感表达增强是对话层独立能力，可与 Glossa 并行不冲突，也可作为 Glossa 的情感模块。 |
| "帕姆帮帮自己会迭代" | 帕姆帮帮目前是"答疑+闲聊"，情感浓度与角色共情仍浅；我们的引擎 1 个月 PoC 即可对比体验差距。 |
| "500 万贵" | 相对 780 亿营收≈0.006%；且按 ARPU 测算，情感增强带来的留存/付费增量一个版本即可覆盖。 |
| "我们走投资路线（投 MiniMax 等）" | 投资解决的是模型底座，情感增强是模型之上的独家能力——没有可投资的同类标的（全球唯一公开可授权的推理期情感引擎）。 |
| "合规上拟人化有风险" | 游戏内角色陪伴配合显著标注+未成年人护栏，正落在新规鼓励方向；引擎是"情感表达质量"不是"虚拟亲密关系"。 |
| "考虑一下" | 独家窗口不等人：腾讯/网易也在看同一授权，早签锁定游戏行业独家。 |
| 关于薪资条款的质疑 | 最低工资+最低社保是作者对原神/星铁的真挚热爱（可举证游戏理解），写不写入协议均可，纯加分项。 |
