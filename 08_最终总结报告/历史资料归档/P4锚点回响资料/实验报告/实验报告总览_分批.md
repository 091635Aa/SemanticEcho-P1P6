# P4 锚点回响 实验报告总览（分批）

> 本总览按实验批次/里程碑组织，汇总 P4 锚点回响（Anchor Echo）的全部实证批次。数据均来自 `实验报告\` 目录下迁移的原始 JSON / 报告，未做任何编造；拿不准或口径受限的数字以 `~` 标注并注明来源。

## 方案一句话

**锚点回响（Anchor Echo）**：把模型自身 token-embedding 权重当作**只读接口**，用 6 维情感锚点词集（每维 50 词，含网络流行语）质心构建稠密余弦打分表 S∈R^{V×K}（V=151936，仅 1.8MB fp16），解码时 `logits[w] += β·tanh(S[w]·v_target/T_anchor)` 做**嵌入空间稠密情感引导**——与 P1（表示空间）、P3（概率空间）正交，零 hook 开销、权重零修改（只读校验 sum/data_ptr 一致）、闭源 API 可经 logprobs/提示模式降级。批实验从灵感验证 → 单模型对照 → 参数扫描 → 五基准评测 → 多模型泛化 → 三正交叠加 → 接口降级，最终达成 HeartBench +21.7%、TuringBench 人似度 +200%、LLM-Judge +人设 +56.25%。

## 批次详解

### 批次0 灵感验证（Task1，2026-08-10）

- **目的**：定稿 P4 核心前提——"模型 embedding 空间中，情感锚点质心具备清晰、可分离的方向"，并证明只读约束。
- **方法**：Qwen2.5-1.5B（fp16，vocab=151936，hidden=1536，tied），6 维情感锚点词集（每维 10 中文种子词）质心 = 均值后 L2 归一化；词向量 = 各 token 嵌入均值。
- **指标数据**（`灵感验证报告.md` / `对照结果\灵感验证结果.json`）：
  - **方向分离度**：6 维 t 统计量 9.3~17.6（温柔 10.83/开心 14.31/难过 11.28/愤怒 9.25/害怕 17.58/平静 9.49），均值差 +0.35~+0.50；全情感词（60 个）max 余弦 0.5486±0.1165 vs 全中性词 0.1495±0.0478；**平均 t=12.12**（原始模式）> 11.69（层归一化）→ 层归一化无增益，主模式选原始 embedding。
  - **只读证明**：W_e.sum() 与 data_ptr 构建/打分前后完全一致（-9400.000000 / 30690902016）。
  - **近义覆盖**：词库外 10 个网络情感词 P3 稀疏全 0 → P4 稠密平均 0.1907（7/10 词 ≥0.19 被识别：扎心/心累/崩溃/泪目/治愈/宠溺/孤寡；上头 0.037/内耗 0.069/破防 0.126 弱）；未过"均值+2σ"阈值（0.2451），判定弱成立；top-30 高频普通 token 平均 0.1087 无显著误报。
- **结论**：方向分离度强成立（基石），只读成立，近义覆盖部分成立——进入后续 Task。

## 指标口径说明

- **语义熵**：生成序列逐 token softmax 分布熵均值（fp32 计算规避 fp16 clamp 下溢）；P4 要求熵 ≥ 裸 × 0.95（熵不退化判定）。
- **重复率**：token 级 2-gram 重复比例；无坍缩判定 = 重复率 − 裸 ≤ +0.05。
- **情感命中率**：生成 token 中命中"锚点库词集 + cnsenti 词库"的比例（token 级）；另有文本级命中率（命中词数/文本词数）用于接口降级对比。锚点打分对与目标方向相似的非词集普通词也会推高（不进命中计数），故命中率增益为保守下界。
- **β / T_anchor / 稀疏阈值**：β = 注入强度；T_anchor = 打分温度（tanh 饱和度）；稀疏阈值 = 只对 `tanh(S[w]·v_target/T_anchor) > 阈值` 的 token 加偏置（0.0 为向后兼容默认）。
- **LLM-Judge win_rate**：30/60 条样本配对盲评（AB 对调双份投票），win_rate = 配对胜数/配对总数（每样本 2 配对）；P4 单模式判定线为 ≥ 裸 × 1.25。
- **EmoCharacter**：10 角色×4 轮，匹配/错配 fidelity、一致性识别率（二选一）、中性下限 fidelity；判定线 fidelity ≥ 裸-5%。
- **HeartBench**：官方 296 条抽样 20 题，7B 裁判按官方 rubric 逐条 0/1 打分 + norm_score（0–100）。
- **TuringBench（中文体系）**：TF-IDF(1-2gram)+LR 检测器每模式独立训练，human_likeness = 测试集 AI 文本被判为"人类"比例；锚点后检测器留出准确率 0.883→0.650（更难区分）。
