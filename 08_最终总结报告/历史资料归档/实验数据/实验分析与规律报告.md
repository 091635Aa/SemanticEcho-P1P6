### 规律 1：Qwen3 系列对回响注入极度敏感（坍缩阈值远低于 Qwen2.5）
- Qwen3-0.6B（λ=0.41）、Qwen3-1.7B（λ=0.10）直接坍缩（重复率 0.85~0.92，熵降至 0.3）
- 同为 hidden=2048：Qwen2.5-3B（λ=0.10）稳定 vs Qwen3-1.7B（λ=0.10）坍缩
- **结论：λ 不能只按 hidden_dim 定标，必须引入"模型代数/架构族"因子。Qwen3 需要 λ ≈ Qwen2.5 的 1/3~1/5**

### 规律 2：hidden_dim 相同 ≠ 最优 λ 相同
- hidden=2048 组：Qwen2.5-3B 稳定 λ=0.10；Qwen3-1.7B 需更小；SmolLM2-1.7B 也偏强（重复率 0.45）
- hidden=3072 组：Phi-3.5 λ=0.082 稳定（重复率仅 0.04）
- **结论：跨架构通用公式需加入架构特征（层数/头数/代数/训练范式），仅 hidden_dim 不够**

### 规律 3：4bit 量化使回响重复率普遍升高（量化放大注入敏感度）
- 0.5B：fp16 回重 0.24 → 4bit 0.39；1.5B：0.05 → 0.13；Gemma：0.41 → 0.47
- **结论：量化模型应自动下调 λ（约 ×0.7~0.8）或启用更激进保留策略**

### 规律 4：中文情感命中率与模型中文能力强相关
- 中文模型命中率 0.12~0.21；多语 Gemma 0.41（词库匹配意外高）；英文 Phi-3.5 ≈ 0.0003
- **结论：情感过滤器词库对英文模型几乎无效——命中率可作为"语言适配度"探针**

### 规律 5：小模型回响熵提升大，大模型更稳
- 0.5B 熵 +27%、1.5B +42%、3B +45%、7B +45%但重复率仅 0.03（最稳）
- **结论：模型越大，回响越稳（可用更强注入）；模型越小越需保守 λ + 保留策略**

### 规律 6：Qwen3-4B 是 Qwen3 系列中唯一未坍缩的（hidden=2560，λ=0.098）
- 回熵 +51%，重复率 0.18 偏高但可用
- **结论：Qwen3 大尺寸（≥4B）对注入的耐受性显著提升**

## 三、通用最大化激活方法（设计启示）

1. **λ 通用公式升级**：λ = 基础公式(hidden_dim) × 架构族因子 × 量化因子
   - 架构族因子（建议初值）：Qwen2.5=1.0，Qwen3=0.3（1.7B 以下）/0.6（4B），Gemma=0.7，SmolLM=0.5，Phi=0.8
   - 量化因子：fp16=1.0，4bit=0.75
   - 需经"坍缩检测"在线校准（见下）
2. **在线坍缩检测（按需激活核心）**：生成前几 token 若 熵 < 阈值(如 0.6) 或 重复率 快速攀升 → 自动将 λ 减半并重试/降级回响层
   - 该机制可将 Qwen3-0.6B/1.7B 从"坍缩"拉回"有效"
3. **按层激活规则**：
   - 回响层：情感密度高的任务增强，低情感密度任务降级（复用动态策略 B/C）
   - LoRA 层：按需挂载（peft），失败自动回退基座
   - RAG 层：检索命中质量低于阈值时自动关闭，避免噪声注入
4. **四层全自动**：统一入口读取模型元信息（hidden_dim/代数/量化）→ 自动推荐 λ/γ/τ → 各层按需激活 → 坍缩自动兜底
