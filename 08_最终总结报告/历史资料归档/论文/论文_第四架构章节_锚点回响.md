# 模块十五 · 正文

## 15.1 研究动机：前三代方案的边界

前三代方案分别在三个"空间"上工作，各自解决了情感表达链路中的一个环节，但也各自留下了边界：

1. **P1 语义回响（表示空间）**：通过 forward hook 捕获生成过程中被丢弃 token 的 hidden_state 进入回响池，再以随机投影矩阵把池质心投影回 logits 空间注入。它解决了"情感底色的持续性"，但存在三个工程瓶颈：**投影矩阵为固定随机矩阵**（hidden×V，1.5B 约 933MB fp32），**语义方向不可解释**（随机方向与情感方向无对应关系），且**强依赖 forward hook**（必须本地模型、无法下沉到 API 场景）。
2. **P2 通用兼容层（配置空间）**：解决"跨模型参数适配"，本身不注入，是参数体系——它回答了"每个模型该用多大强度"，但没有回答"往哪个情感方向推"。
3. **P3 情感潮汐解码（概率空间）**：用外部 VAD + 稀疏情感词表对 logits 做乘性重加权（`p'(w)=p(w)^(1-α)·q_emo(w)^α`）。它解决了"方向与密度控制"，但**词表稀疏（≈千级情感 token）**：词表外 token 得分为零，未命中情感词（尤其网络流行语：破防/泪目/内耗）无法被引导；且 OOV 词在 1.5B 的中文 BPE 词表上高频出现，稀释了引导覆盖面。

**P4 的关键观察**：`get_input_embeddings()` 暴露的 token-embedding 权重 `W_e` 是一张天然的、稠密的、可解释的情感语义地图——词表中每一个 token 的嵌入向量都与"温柔/开心/难过/愤怒/害怕/平静"六个方向存在确定的余弦关系。既然模型自己"知道"每个词的情感语义，为何不把这张地图直接用作注入接口？

由此提出第四代方案的核心主张：

> **锚点回响＝用模型自身的 token-embedding 权重 `W_e` 作为只读映射接口，把「K 维情感锚点质心」的稠密余弦打分做成低秩 logits 偏置，按会话目标情感权重 `v_target` 极性定向注入——不写权重、不挂钩子、全词表覆盖、可降级到闭源 API。**

## 15.2 方法

### 15.2.1 操作空间：嵌入空间（Embedding Space）

P4 与前三代最本质的区别在于操作空间。P1 操作 hidden_state（表示空间）、P3 操作 logits 分布（概率空间）、P4 操作的是**词表嵌入空间**：把模型自身的 embedding 权重当作一个只读的"情感-语义映射接口"。四种方案沿"接口位置"构成递进：表示空间（P1）→ 概率空间（P3）→ 嵌入空间（P4），外加贯穿全程的配置空间（P2）。

### 15.2.2 接口映射：情感锚点质心与打分表

设词表大小为 $|\mathcal{V}|$、嵌入维度为 $d$。锚点库维护 $K=6$ 个情感维度的种子词集（每维 50 个中文词，纳入网络流行语：破防/泪目/内耗/扎心/心累/宠溺），逐词取 token 嵌入均值得到词向量，再按维度求均值并做 L2 归一化，得到情感锚点质心矩阵 $E \in \mathbb{R}^{K \times d}$。

在此基础上一次性预计算**稠密余弦打分表**：

$$S[w,k] = f_k(w) = \cos(W_e[w],\, e_k) = \frac{W_e[w]\cdot e_k}{\lVert W_e[w]\rVert \cdot \lVert e_k\rVert}, \qquad S \in \mathbb{R}^{|\mathcal{V}|\times K}$$

打分表规模 $|\mathcal{V}|\times K\times 4\text{B}$（Qwen2.5-1.5B：$151{,}936\times6\approx3.6$MB fp32 / 1.8MB fp16），对比 P1 投影矩阵 $d\times|\mathcal{V}|$（约 933MB fp32）内存下降约 3 个量级。**全部计算基于 `W_e.detach().float()` 只读副本**，原始权重仅用 `sum`/`data_ptr` 断言校验（实测 `sum_before=sum_after=-9400.0`、data_ptr 一致，权重零修改）。

### 15.2.3 目标决策：VAD→锚点空间映射与极性定向

目标层复用 P3 的潮汐感知器/决策器（cnsenti VAD 测量 + 会话轨迹），由新增的 `目标决策器` 完成 VAD→锚点空间映射：

1. **目标状态**：$V_{target} = V_{用户}\times\beta_{共情} + V_{轨迹均值}\times(1-\beta_{共情})$（角色主导时再叠加角色 VAD）；
2. **方向余弦 + 平方放大**：$g_k = (V_{target}\cdot 原型_k)/(\lVert V_{target}\rVert\lVert 原型_k\rVert+\varepsilon)$，$v_k = 原型强度_k\cdot g_k\cdot|g_k|^p$（p≥1 锐化高匹配维，保持极性）；
3. **多源融合**：$v_{target} = w_{潮汐}\cdot v_{潮汐} + w_{思考链}\cdot v_{思考链} + w_{指令}\cdot v_{指令}$，来源权重默认 {潮汐:0.5, 思考链:0.3, 指令:0.2}，最终 L2 归一化；
4. **角色感知**（扩展）：命中内置 15 角色锚点基调表时 $v_{target}=0.7\cdot v_{角色}+0.3\cdot v_{用户}$（角色基调跨轮固定、用户部分每轮更新）；
5. **强度自适应**：$\beta = \beta_{基}\times(1+\Delta arousal)\times\min(1, 活跃度\times2.5)$，封顶 $\beta_{上限}$。

### 15.2.4 极性定向 tanh 注入（核心公式）

表达层 `锚点解码器` 在每步解码对 logits 做**极性定向有界注入**：

$$a(w) = S[w]\cdot v_{target} = \sum_{k=1}^{K} f_k(w)\cdot v_{target,k} \qquad \text{（极性内积，正=朝目标情感方向）}$$

$$\text{logits}[w] \mathrel{+}= \beta\cdot\tanh\!\left(\frac{a(w)}{T_{anchor}}\right)$$

**tanh 有界化的三个理由**：① 每个 token 的 logits 偏移有硬上限 $|b_{anchor}(w)|\le\beta$，β 直接等于"最大注入幅度"，从机制上杜绝过注入坍缩；② $a(w)/T_{anchor}$ 量级可控（$|f_k|\le1$、$\lVert v_{target}\rVert_2=1$，内积量级 ≈ $O(\sqrt{K})$），$T_{anchor}\in(0.1,0.5)$ 放大弱信号、饱和强信号，与 P1 的 λ 语义解耦；③ 弱信号区 $\tanh(x)\approx x$ 保持线性可调，与 P3 乘性重加权"有界插值"精神一致。非情感 token 余弦自然稀疏、情感方向 token 被抬升，且**零 hook 开销**（一次查表 + 向量乘）。

同时配备**在线退化兜底**（每 40 token 检查语义熵 <0.6 或 2-gram 重复率 >0.6 → β×0.5，连续 3 次 → β=0 锚点通道静默）与**句内密度控制**（目标方向情感词密度超限 → 注入幅度 ×0.3，防情感词堆砌）。

### 15.2.5 自动适配（P2 扩展）

扫描表从三元组 (λ,γ,τ) 扩展为五元组 (λ,γ,τ,β,T_anchor)：hidden 896→(1.0,0.4)、1536→(0.8,0.3)、2048→(0.6,0.3)、3584→(0.5,0.2)。未命中走公式兜底 $\beta = \beta_{基础}(hidden)\times 架构族因子_{锚点}\times 量化因子$（Qwen3≤1.7B 因子 0.4、Gemma 因子 0.8、4bit 因子 0.75），未注册模型一律保守 β=0.5 起步并配合在线坍缩检测。

### 15.2.6 三级接口降级

为下沉到闭源 API 场景，P4 设计三级降级链路（判定顺序 `判定接口()`：embedding 可用 → logprobs 可请求 → 纯黑盒）：

| 级别 | 前置条件 | 打分方式 | 注入方式 |
|---|---|---|---|
| ① 本地 embedding 直读（主路径） | `get_input_embeddings()` 可用 | 全词表预计算 $S\in\mathbb{R}^{V\times K}$ | $\text{logits} \mathrel{+}= \beta\cdot\tanh(S\,v_{target}/T_{anchor})$ |
| ② API logprobs 近似 | 接口暴露 top-k logprobs | **候选受限打分**（top-100 稠密打分） | 伪 logits 重采样 |
| ③ 锚点提示模式 | 完全黑盒 | 无打分 | 当前维度锚点词注入 prompt |

## 15.3 实验设计

**目标模型**：Qwen2.5-1.5B-Instruct（fp16，cuda:0，RTX 3080 16GB）；**裁判模型**：Qwen2.5-7B-Instruct（手动 bf16 逐张量装载）。**生成配置**：最优定标 (β=0.8, 稀疏阈值=0.0, T_anchor=0.3, K=6)，top_p=0.9, top_k=50, temperature=1.0, repetition_penalty=1.05；**同种子 42** 裸 vs 锚点对照；P4 单模式纯净（默认关闭 P3 人设/身份拦截）。

**五基准**：EmoCharacter（10 角色×4 轮，Fidelity 差分 + 一致性二选一）、LLM-Judge（30 样本配对盲评 AB 正反各一次 + 1-5 分）、HEART-BENCH（英文 MCQ 决策，10 题×2 重复，7B 共情裁判）、HeartBench（中文情感支持，20 题官方 rubric 逐条 0/1 + norm_score）、TuringBench（中文体系 TF-IDF+LR 检测器，30 测试对，human_likeness = 测试集 AI 文本判"人类"比例）。各基准生成与裁判分离进程运行（`--只生成` → 每模式独立 `--只裁判`），P3/原脚本零改动。

**多模型泛化**：Qwen2.5-3B / Qwen3-1.7B / gemma-2-2b 上 LLM-Judge 裸 vs 锚点（30 条同样本、同种子 42，β 由自动适配给出；Qwen3 用 `enable_thinking=False` + `<think>` 剥离）。

**三正交叠加 + 双裁判**：四模式（裸/锚点仅A/回响仅B/全开 A+B+C）30 条样本生成，同一批回复由三个裁判独立盲评（本地 7B 8bit、deepseek-v4-flash、deepseek-v4-pro，思考关），60 配对/模式——控制变量：同回复/同配对/同提示词模板，只变裁判。

**接口降级验证**：5 条情感提示（难过/开心/担心/委屈/中性），种子 42，max_new_tokens=128，三级别（本地/logprobs top-100/提示）对照。

**结果分析**：

1. **HeartBench +21.7%（P4 最强项）**：锚点句子停止产出 22~78 字短回复，对齐真人对话长度；情感方向贴合对话末句用户情绪。同基准 P3 潮汐为 **-9.4%**——**P4 锚点在"人味儿 rubric"任务上显著优于 P3**。机制：rubric 打分对"自然口语、贴合情绪"敏感，而嵌入空间稠密引导恰好提升情感词命中与表达贴合度，且 tanh 有界注入不牺牲多样性（熵为裸的 109.9%）。
2. **TuringBench +200%**：裸 1.5B 生成大量"作为AI助手/我叫Qwen/我不能继续"身份泄漏与列点说教，检测器留出准确率 0.883 秒识别；锚点文本更短、情感共鸣更强（"……这种自我质疑和不安是很常见的心理状态，但它不是永远的状态，我们可以努力改变它"），检测器留出准确率降至 0.65。**锚点引导使小模型文本与真人中文写作更难区分**。
3. **LLM-Judge 部分达成**：单模式纯净 +12.49%（未达 +25% 线），+P3 人设 +56.25% 达成（且相对裸+人设仍有 +8.71% 边际）。归因：人设系统提示是主增益来源；P4 纯净模式无 P3 的 AI 腔三通道抑制（该模块直接针对 LLM-Judge 最大破绽——身份/客服腔），故单模式幅度低于 P3 潮汐 v4.1（+27%），但锚点通道在风格对齐后提供情感方向的正向边际。
4. **HEART-BENCH 边缘持平**：共情 0.76→0.72（-5.26%，略低于 -5% 线）。归因与 P3 一致：英文 MCQ 决策输出受 JSON 强约束 → 分布低熵、锚点影响面小（裸/锚点文本高度相似，仅个别题选项漂移）；accuracy 0.5→0.2 属 MCQ 选项漂移非共情退化——**该基准对"情感引导解码"类方案是钝感基准**。
5. **EmoCharacter 受天花板限制**：识别率 0.90→0.70，但匹配 fidelity 0.8075 ≥ 裸-5%、真实一致性 0.960 与裸持平、中性下限 0.70 持平无角色情感污染；角色感知锚点修复了"毒舌但心软的损友"（裸/普通锚点均 ✗ → 角色感知 ✓）。卡点收敛为 **1.5B 模型第 3/4 轮固有开头模板**（"嗯？谢谢？/太好了！"，裸模式同样存在）与打乱集跨角色雷同，非锚点通道本身所致。

## 15.5 与前三代的关系：正交可叠加

P4 与前代不是替代关系，而是**同一"情感表达工程"在第四个操作空间上的正交扩展**：

- **与 P1（表示空间）**：P4 把 P1 的"固定随机投影矩阵"替换为"模型自身 embedding 接口产出的低秩打分表"——质心（hidden_state 池 → K 维锚点质心）、投影（随机高斯 → 余弦打分）、注入（加偏置 × λ → β 与 tanh 有界化）三个环节一一对应，但 P4 一次性构建、生成期零 hook 开销；两通道叠加验证：全开（锚点+回响+潮汐）熵 1.67 > 任单通道，无坍缩。
- **与 P2（配置空间）**：自动适配体系原样扩展（扫描表五元组 + 公式兜底 + 架构族/量化因子），三模型实测证明三路径（扫描表/族因子/公式兜底）均可用且无坍缩。
- **与 P3（概率空间）**：感知/决策/表达三层结构完全复用（目标层共用潮汐决策器输出，v_target 与 α 同源保证叠加方向一致）；P4 的嵌入空间稠密打分与 P3 的稀疏词表乘性重加权互补——**稀疏词表覆盖"已知情感词"，稠密余弦覆盖"词表外近义词"**。叠加验证：P4+P3 人设 LLM-Judge +56.25%（相对裸+人设仍有 +8.71% 边际）。
- **与第 0 层（权重级）**：P4 保持"零修改权重"的推理期定位，是第 0 层训练期方案的互补项——权重级方案改"自我认知"，P4 只改"当下一句话的情感方向"。

**结论**：P4 锚点回响与前三代（及第 0 层）正交可叠加，是语义回响家族"从表示到概率到嵌入"空间递进的第四块拼图。

## 15.6 局限

1. **EmoCharacter 天花板**：一致性二选一识别 0.70 未追平裸基线 0.90——1.5B 模型第 3/4 轮固有开头模板（"嗯？谢谢？/太好了！"，裸模式同样存在）与打乱集跨角色雷同是主因；fidelity 维度无显著退化、无角色情感污染，证明瓶颈在模型表达上限而非锚点通道。
2. **纯净模式 AI 腔**：P4 单模式纯净（默认关闭 P3 人设/身份拦截/AI 腔抑制）在 LLM-Judge 上仅 +12.49%（未达 +25% 线）；云裁判（flash/pro）对 1.5B AI 腔绝对否决使三正交叠加的绝对 win_rate 未达 +18% 判定线。AI 腔抑制是 P3 的强项，P4 与其正交叠加（+人设 +56.25%）方兑现增益。
3. **3B 方差内负向**：Qwen2.5-3B 上 LLM-Judge -5.86%（60 配对差 1 胜，绝对差 -0.0166），降 β 复测 -17.65% 更差——判定为配对盲评随机方差内负向，不构成锚点通道失效，但提示"非所有模型都在 LLM-Judge 单模式上获益"。
4. **低熵强约束基准钝感**：HEART-BENCH 类英文 MCQ 决策（JSON 约束）对情感引导解码钝感（-5.26% 边缘持平），锚点优势集中在自由对话场景。
5. **闭源 API 的粒度下限**：③ 提示模式粒度粗（维度级而非 token 级），本地模拟偶有"用户：/回复："格式残留（生产端经 API chat template 自然消除）。

## 15.7 本章小结

锚点回响（P4）把"情感引导解码"推进到嵌入空间：以模型自身 token-embedding 为只读接口，K 维情感锚点质心的稠密余弦打分 + 极性定向 tanh 注入，在**零权重修改、零 hook 开销、1.8MB 打分表**的工程约束下，达成 HeartBench **+21.7%**、TuringBench human_likeness **+200%**、LLM-Judge +人设 **+56.25%** 的实证增益，多模型 3/3 可用（2/3 泛化为正），三级接口降级链路完整（①≈②>③）。与 P1/P2/P3 正交可叠加，共同构成"从表示到概率到嵌入"的情感表达工程空间递进。
