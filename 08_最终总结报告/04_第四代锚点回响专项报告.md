# 第四代锚点回响（Anchor Echo, AE）专项报告

## 3 分钟版 · 供单独向大厂宣讲 P4

> 撰写：2026-08-10 ｜ 数据源：`P1_4\P4_锚点回响\` 全部实验报告（灵感/对照/扫描/五基准/多模型/三正交/接口降级）
> 目标模型：Qwen2.5-1.5B-Instruct 原版基座（无 SFT/LoRA），同种子 42，7B 裁判

---

## 一、一句话

**锚点回响 = 用模型自身的 token-embedding 权重 W_e 作为只读映射接口，把「6 维情感锚点质心」的稠密余弦打分做成低秩 logits 偏置，按会话目标情感 v_target 极性定向注入——不写权重、不挂钩子、全词表覆盖、可降级到闭源 API。**

核心卖点三个"零"：**零权重修改**（sum/data_ptr 断言证明）、**零 hook 开销**（一次查表 + 向量乘）、**零门槛接入**（闭源 API 三级降级，任何大厂现有 API 无需改权重即可情感增强）。

## 二、四代位置图（语义回响家族）

| 代 | 名称 | 操作空间 | 改权重 | 需本地权重 | 闭源 API | 代表成果 |
|---|---|---|---|---|---|---|
| P1 | 语义回响 | 表示空间（hidden_state 钩子） | 否 | ✅ 必须 | ❌ | 熵 +27~45% |
| P2 | 通用兼容层 V2 | 配置空间（自动调参） | 否 | ✅ 必须 | ❌ | 任意模型自动适配 |
| P3 | 情感潮汐解码 ETD | 概率空间（乘性重加权） | 否 | 可选 | ✅ | LLM-Judge 混合 +91% |
| **P4** | **锚点回响 AE** | **嵌入空间（词表坐标锚定情感温度）** | **否（只读证明）** | 可选 | **✅ 三级降级** | **HeartBench +21.7%、TuringBench +200%** |

继承关系：P4 把 P1 的"质心投影"从 hidden_state 迁移到静态 embedding 接口——用模型自己的词表坐标锚定情感方向，同时**补上 P3 词库稀疏的短板**（P3 只认识词库里的情感词，破防/泪目/内耗等网络流行语得分为零；P4 稠密余弦对词库外近义词 7/10 可识别）。四代正交可叠加。

## 三、机制三件套

```
① 锚点库     6 维情感锚点（温柔/开心/难过/愤怒/害怕/平静）× 每维 50 词（含网络流行语）
             → 词向量均值 → 维度质心 → L2 归一化 → 一次性预计算稠密余弦打分表 S ∈ R^{V×K}
             （1.5B：151,936×6 ≈ 3.6MB fp32 / 1.8MB fp16，vs P1 投影矩阵 933MB，降 3 个量级）
② 目标决策器  复用 P3 潮汐感知器/决策器（VAD+会话轨迹）→ VAD→锚点映射 → 多源融合 → 角色感知
             （15 角色基调表）→ 强度自适应 β；自动适配沿用 P2 扫描表五元组 + 架构族/量化因子
③ 锚点解码器  logits[w] += β·tanh(S[w]·v_target / T_anchor)（有界注入，|偏移| ≤ β，机制上防坍缩）
             + 在线退化兜底（熵<0.6/重复率>0.6 → β×0.5，3 次 → β=0）+ 句内密度控制
```

**核心公式**：

```
S[w,k]   = cos(W_e[w], e_k)                 # 全词表稠密余弦打分（V×K）
a(w)     = S[w] · v_target                  # 极性内积（正=朝目标情感方向）
logits[w] += β · tanh(a(w) / T_anchor)      # 极性定向 tanh 注入（有界，非情感 token 余弦自然稀疏）
```

## 五、双裁判交叉验证（三正交叠加，控制变量：同回复/同配对/只变裁判）

| 模式 | 本地 7B win_rate | deepseek-flash | deepseek-pro | 平均熵 | 平均长度 |
|---|---|---|---|---|---|
| 裸 | 0.1500 | 0.0000 | 0.0167 | 1.4197 | 134.9 字 |
| 锚点（仅A） | 0.2333 | 0.0000 | 0.0167 | 1.4804 | 48.4 |
| 回响（仅B） | 0.1333 | 0.0000 | 0.0000 | 1.5368 | 149.4 |

- **三通道叠加无坍缩**：熵 1.42→1.67（+17%）、回复长度 135→54 字对齐真人短回复；与 P3 人设叠加方在 LLM-Judge 兑现绝对增益（+人设 0.4167 已验证）。

## 六、接口降级（闭源 API 可用性的实证）

| 级别 | 接口 | 平均熵 | 情感命中(文本) | 与本地差异 | 判定 |
|---|---|---|---|---|---|
| ① 本地（主路径） | `get_input_embeddings()` 直读 | 1.4915 | 0.0210 | 基准 | 最强最细 |
| ② logprobs 近似 | top-100 候选受限注入 | 1.4815 | 0.0210 | **熵差仅 0.67%、输出逐字一致** | ✅ 无损退化 |

## 七、商业契合点（对大厂）

1. **MaaS 情感缺口 = 接口层方案的现成市场**：CompanionBench 证实全行业共同弱点是"情绪调节与实质关系支持"——我们的 P4 是**挂在现有 API 之上的后处理增强层**，云厂商无需动基座、无需重训练，挂载即用（阿里百炼/腾讯混元/华为 MaaS/DeepSeek V4 API 均可）。
2. **端侧只读方案**（小米小爱/华为小艺）：打分表 1.8MB、显存增量 <3.6MB、延迟 <5%，端侧 4B 可挂载，无数据出境、无隐私负担。
3. **角色 IP 情感锚点**（米哈游）：6 维情感锚点 + 15 角色基调表，角色感知锚点已修复"毒舌但心软的损友"类复杂角色，角色一致性/OOC 直接受益。
4. 商业授权同 SemanticEcho-Hub 价目表（大厂年费 500 万+/年 起）。

## 八、局限（诚实清单）

1. **纯净单模式 LLM-Judge 增益有限**（+12.5%，需叠加 P3 人设才达 +56.25%）；AI 腔抑制是 P3 强项，P4 与其正交叠加方兑现 LLM-Judge 增益。
2. **EmoCharacter 受 1.5B 模板天花板限制**（裸识别率 0.90 已饱和，卡点在第 3/4 轮固有开头模板，裸模式同样存在；fidelity 不退化、无角色情感污染）。
3. **Qwen2.5-3B 上 LLM-Judge -5.86%**（60 配对差 1 胜，方差内负向；降 β 复测更差）——非所有模型在单模式下获益，多模型可用性 3/3、泛化提升 2/3 为正（Qwen3-1.7B +6.91%、gemma-2-2b +28.53%）。
4. **低熵强约束基准钝感**（HEART-BENCH 英文 MCQ 边缘持平），优势集中在自由对话场景。
5. **提示模式粒度粗**（维度级而非 token 级），是纯黑盒 API 下的兜底而非主路径。
