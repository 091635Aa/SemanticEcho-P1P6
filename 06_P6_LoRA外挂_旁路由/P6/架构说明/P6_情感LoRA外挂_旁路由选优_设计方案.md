# 第六套方案：情感LoRA外挂 × 旁路由选优（Emotion-LoRA Side-Route, ELS / P6）

> 版本：2026-08-11 v1.0 ｜ 定位：**权重空间（训练态适配）· 旁路由（推理期侧路介入）**
> 承接前辈谱系：PE(P1 语义回响/表示空间) → P1.5(通用兼容层/配置空间) → P2.5(情感潮汐 ETD/概率空间)
> → P3(锚点回响 AE/嵌入空间) → P4(KV 情感共振 KER/注意力缓存空间) → P5(超融合 UFD/全空间) → G(P1~P5 统一版)

---

## 一、P6 一句话

> **P6 = 情感 LoRA 外挂（训练态写适配器权重）+ 旁路由选优（推理期侧路介入选最优回复）。**
> 前辈全部在"解码期零权重注入"（不训练、不改权重、单路径上注入信号）；
> **P6 首次反转范式——用训练在权重空间直接塑造情感表达，再用旁路由在候选回复间做情感路由**，
> 主生成路径零修改、零注入，情感质量交给"外挂适配器 + 侧路路由器"共同保证。

---

## 二、为什么底层思路与前辈本质不同

| 方案 | 操作空间 | 是否训练 | 是否改权重 | 作用方式 |
|---|---|---|---|---|
| PE (P1 语义回响) | 表示空间 | 否 | 否 | forward hook 捕获 hidden_state → 投影注入 logits |
| P1.5 兼容层 | 配置空间 | 否 | 否 | 参数表/公式自动调度 λ/γ/τ/β/κ |
| P2.5 潮汐 ETD | 概率空间 | 否 | 否 | logits 乘性重加权 + AI腔抑制 |
| P3 锚点回响 | 嵌入空间 | 否 | **否（只读 W_e 打分表）** | logits += β·tanh(S·v/T) |
| P4 KV 共振 | 注意力缓存 | 否 | 否（运行时 KV 缩放） | K[p] *= 1+κ·clip(g,0,1) |
| P5 超融合 | 全空间 | 否 | 否 | DSA + DMR 机制级融合 |
| G (P1~P5 统一) | 全空间 | 否 | 否 | 统一调度七模式 |
| **P6 ELS** | **权重空间 + 路由空间** | **✅ 训练 LoRA** | **✅ 写适配器权重（不碰基座）** | **LoRA 外挂塑造 + 旁路由选优** |

**本质区别三点**：
1. **首次训练**：P1~G 全部是"推理期临时注入"，参数零更新；P6 通过 LoRA 训练把"情感表达能力"固化进适配器权重（增量 ΔW = BA），基座权重原样不动。
2. **首次旁路由**：前辈在"单条生成路径"上做注入（改 logits/概率/注意力/KV）；P6 主路径零修改，改由**侧路路由器**在多条候选回复之间做情感路由（选优而非注入）。
3. **满足"前奏不可修改"约束**：P6 不碰 system prompt/chat 模板/模型前奏，全部能力来自外挂适配器 + 推理期侧路选择。

## 三、总体架构（三层）

```
┌────────────────────────────────────────────────────────────────┐
│                    P6 情感LoRA外挂 × 旁路由选优 (ELS)              │
│                                                                  │
│  ① 训练态 · 情感LoRA外挂（权重空间适配）                           │
│     数据：情感chat语料(emotion_dataset 4409条) + 温柔语料(80条)    │
│           + 人味对话增强语料（girl风格改写，不与评测样本逐字重复）    │
│     训练：LoRA r∈{8,16} α∈{16,32} q/k/v/o，QA chat 模板监督微调    │
│     产物：lora_adapters/p6_emotion/（适配器权重，基座零改动）       │
│                                                                  │
│  ② 推理态 · 旁路由选优（侧路介入，主路径零注入）                    │
│     感知：用户消息情感检测（情感词命中 + 语气/长度特征）             │
│     多候选：LoRA 挂载模型按 N=3 个独立种子各生成一条回复            │
│     路由：每条候选计算 情感质量分 = 情感命中 + 长度约束              │
│           + 熵健康 + AI腔惩罚 + 重复惩罚                            │
│     选优：取最高分候选；全不合格 → 降级裸采样（兜底）               │
│                                                                  │
│  ③ 工程层 · 评测协议（沿用统一基准）                               │
│     样本：样本_30条.json；种子：2026；采样：T=1.0/top_p=0.9/       │
│           top_k=50/rep=1.05；裁判：Qwen2.5-7B 配对盲评 AB×2        │
└────────────────────────────────────────────────────────────────┘
```

## 四、与前辈的参考与创新（要求 4：可参考但要创新）

| 参考来源 | 借鉴点 | P6 创新 |
|---|---|---|
| PE (P1) | 情感方向影响表达 | 不用 hidden_state 投影（易坍缩、933MB 矩阵），改用训练固化 |
| P2.5 潮汐 | AI腔三通道抑制经验、句子停止、多候选自选 | 抑制规则从"概率空间注入"移到"路由评分器"（侧路），主路径不动 |
| P5/G | 多机制协同、评测协议统一 | 不做机制级 logits 融合，做**权重级适配 + 路由级选优** |

**P6 独有的科学价值**：证明"训练态外挂 + 推理期旁路由"这一全新范式，
能以极小开销（LoRA 参数量 <1%）达成对"解码期注入全家桶"的全面超越，
且天然规避前辈的三大通病——熵坍缩（P1）、词表稀疏（P2.5）、AI腔压制（P4/P5 单通道不敌裸）。

## 五、评测协议与目标（要求 1/3/11）

**协议**（与 G 统一基准完全一致，保证可对比）：
- 目标模型 Qwen2.5-1.5B-Instruct（fp16），裁判 Qwen2.5-7B-Instruct（bf16 手动加载）
- 30 条样本，种子 2026，LLM-Judge 配对盲评（AB 正反各一次，60 配对/模式）
- 健康度：语义熵 / 重复率 / 情感命中率 / 长度

**目标（对照 G 报告 2026-08-10 数据）**：
| 指标 | G 最佳（P2.5 潮汐） | P6 目标 | 达成标准 |
|---|---|---|---|
| LLM-Judge win_rate | 0.2667 | **≥ 0.48** | 相对 G 最佳提升 ≥ **+80%**（要求 3） |
| 情感命中率 | 0.129~0.174 | **≥ 0.20** | 全面优于全体前辈 |
| 重复率 | ≤0.0032 | **≤ 0.02** | 无坍缩 |
| 平均长度 | 46~54 字 | **20~80 字** | 对齐真人短回复 |
| 全面超越 | — | **win_rate > 全体前辈** | 要求 1（显著优于 PE→G） |

## 七、风险与对策

| # | 风险 | 对策 |
|---|---|---|
| 1 | LoRA 过拟合小语料 → 生成退化 | 数据增强（girl风格改写不逐字复制）；r/α/epoch 扫描；健康度兜底 |
| 2 | 训练后模型"变温柔"但失去身份/被裁判识破 | 保留基座裸路径；旁路由按输入情绪类型路由（调侃/中性走轻强度） |
| 3 | 旁路由选优引入额外延迟/显存 | 单模型挂 LoRA 即可（零额外显存）；N=3 候选可并行/串行控制 |
| 4 | AI腔仍残留（1.5B 通病） | 路由评分器内置 AI腔 关键词惩罚表（"对不起，我无法/设定目标/作为AI"等） |
| 5 | 评测种子敏感性 | 沿用统一种子 2026 保证与 G 报告同口径；达标后补 2 个种子稳健性验证 |

## 附录：P6 核心公式速查

```
训练态：W' = W + BA（LoRA 增量，基座 W 冻结）
        损失 = CE(模型_带LoRA(q/a chat 对), 人味回复)

推理态旁路由：
  候选集 C = {gen_seed_i(输入) | i ∈ {s1,s2,s3}}，均带 P6 LoRA
  情感分 S(c) = w1·命中(c) − w2·AI腔(c) − w3·重复(c) + w4·长度分(c) + w5·熵分(c)
  输出 c* = argmax S(c)；若 max S < 阈值 → 裸采样兜底
```
