# 语义回响家族（Semantic Echo Family）· P1~P6 超大合体仓库

> **一句话**：一套"让 AI 表达更有情感"的推理期/训练期情感增强架构家族全汇总。
> 本仓库是 **P1 → P6 全部方案的合体仓库**：既有完整文档（优缺点 / 适用场景 / 跑分 / 边际效益与效应 / 测试方法），也有**全部实验数据（JSON/MD/CSV）与全部源代码**。

## 〇、家族地图（最终编号）

```
P1  语义回响 SE        表示空间    hidden_state 钩子回响         （本地权重，开山之作）
P1.5 通用兼容层 V2      配置空间    自动适配 λ/γ/τ + 兜底          （调度总开关）
P2.5 情感潮汐 ETD       概率空间    外部 VAD + 采样重加权          （数学上不可能坍缩）
P3  锚点回响 AE         嵌入空间    词表 embedding 只读投影        （零权重只读证明）
P4  KV 情感共振 KER     注意力缓存   KV 有界调制，让模型"看见"情感
P5  超融合解码器 UFD    全空间融合   P1×P1.5×P2.5×P3×P4 机制级耦合
P6  情感导演 EDD        解码期插件    TAD+PIS+OQC 情感导演三件套    （2026 全家族冠军）
P6  LoRA 外挂×旁路由    权重+路由    训练态写适配器 + 多候选选优     （与前辈本质不同）
```

**关键事实**（详见 [09_跑分总表.md](docs/09_跑分总表.md)）：
- **冠军方案**：P6 情感导演 EDD，5 大基准综合 **0.7046**，超 P5（0.6255）+12.6%，全家族第一。
- **次席**：P5 超融合 UFD（0.6255）> P1 语义回响（0.6063）> P2.5 潮汐（0.5878）> P4 KV（0.5748）> P1.5 兼容层（0.5619）> P3 锚点（0.5565）。
- **唯一训练态方案**：P6 LoRA 外挂（还在达标迭代中，当前 LLM-Judge 0.35，目标 ≥0.48）。
- **家族共识**：不训练、不改基座权重（除 P6 LoRA）、作用在生成期；共同兜底纪律（熵<0.6 自动降强度/归零）。

## 三、五个基准与统一口径（全家族可比）

| 基准 | 测什么 | 裁判/口径 |
|---|---|---|
| LLM-Judge | 对真人回复的盲评胜率（win_rate） | Qwen2.5-7B AB 配对 ×2 |
| HeartBench | 情感/共情 rubric 分 | 官方 rubric |
| HEART-BENCH(FEEL) | 共情/一致性/有效决策率 | 7B 裁判 |
| TuringBench | human_likeness 人似度 | TF-IDF+LR 检测器 |
| EmoCharacter | 角色匹配 fidelity / 一致性识别率 | 7B 裁判 |

统一协议：30 条样本（含真人 girl 回复）、种子 2026、Qwen2.5-1.5B fp16 主模型、
temp=1.0 / top_p=0.9 / top_k=50 / rep_pen=1.05 / max_new=128、零前奏修改。
详见 [docs/11_测试指南.md](docs/11_测试指南.md)。
