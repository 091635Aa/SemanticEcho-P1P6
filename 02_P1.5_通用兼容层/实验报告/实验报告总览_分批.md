# P2 通用兼容层 实验报告总览（分批）

> 本总览按实验批次/里程碑组织，汇总 P2 通用兼容层（跨模型自动适配层）的全部实证批次。数据均来自 `实验报告\` 目录下迁移的原始 JSON / CSV / 报告，未做任何编造；拿不准或口径受限的数字以 `~` 标注并注明来源。

## 方案一句话

**通用兼容层**：把 P1 语义回响从"0.5B 单模型可用"扩展为"跨模型自动适配"——为每个模型注册 λ/γ/τ 五元组扫描表，对未注册模型用 `λ = 基础公式(hidden_dim) × 架构族因子 × 量化因子` 兜底，并配套在线坍缩检测（熵<阈值→λ 减半）。批实验验证了：Qwen2.5 全系/Qwen3-4B/Phi-3.5 有效、Qwen3-0.6B/1.7B 需大幅降 λ（通用注入值救回）、思考链中断注入与 LoRA 融合可用、未注册模型兜底路径成立、λ/γ/τ 联合调优增益 > 单 λ。

## 批次详解

### 批次1 多模型对照（19 配置，2026-08-06）

- **关键数据**（回熵 = 回响熵，回重 = 回响重复率，熵变化 vs 裸）：

- **六大规律**：① Qwen3 系列对注入极度敏感（同 hidden=2048 下 Qwen2.5-3B 稳、Qwen3-1.7B 坍缩，需 λ≈1/3~1/5）；② hidden_dim 相同 ≠ 最优 λ 相同；③ 4bit 量化放大注入敏感度（λ 应 ×0.7~0.8）；④ 情感命中率与中文能力强相关（Phi≈0.0003）；⑤ 模型越大回响越稳（7B 重复 0.03）；⑥ Qwen3-4B 是 Qwen3 系唯一未坍缩档。

## 指标口径说明

- **语义熵**：生成序列逐 token softmax 分布熵均值（与 P1 同源 `回响评估器`）；裸熵为不挂回响的基线熵，回熵为挂载回响后的熵。
- **重复率**：token 级 2-gram 重复比例（runs 均值）；回重 < 0.3 视为安全区间（G2 目标 <0.3）。
- **情感命中率**：生成 token 中命中 cnsenti 情感词库的比例（英文模型如 Phi-3.5 ≈ 0.0003，作为语言适配度探针）。
- **熵变化/提升率**：`(回熵-裸熵)/裸熵`；"+27%"表示回响后多样性提升 27%，负数（如 -73%）表示坍缩。
- **win_rate**：批次4 全链路验证无 LLM-Judge 盲评，用熵/重复率/命中率判定；LLM-Judge 口径自 P3 起引入。
- **CODA 全因子**：模型×量化×上下文长度×模式（基线/回响/RAG/回响+RAG）全组合测试，164 组合。
